## Standards

规范轴独立检查根协作规则、共享约定、冻结区、导航接口、业务副作用和验证方式。初审发现以下问题，已逐项修补：

- **P1 通知原文与旧提案失配**：修改通知后识别失败，旧提案仍可写课。补失败、空串、超长及迟到回复复现；编辑原文或提交重核立即失效旧提案，请求版本阻止旧回复回填。应用期间锁定通知原文、编辑和重核，防止新解析清除正在写入的批次。取消独立编辑仍保留原文与原提案。
- **P2 规则换排放宽用户约束**：首次用控件的readout，换排却重新解析旧输入并回到默认60分钟/4段。现在缓存本次完整readout和原文；换排不丢时长、频率、禁止星期/时段。
- **P2 课程入口遗漏 `scope=saved`**：首页和管理行跳到空白新增表单。修正入参并以编辑页onLoad校验已有课程模式；管理行同类问题是集成时发现的既有缺陷。
- **P2 常驻tab日期/时钟过期**：课表只在首次加载初始化，隔夜仍用旧日期与时刻。onShow刷新真实时钟，显式测试参数仍可固定；首页日期角标同步刷新。
- **共享截图工具兼容回归**：C把PowerShell的JSON结果改成普通字符串，旧验证脚本无法解析。恢复JSON几何接口，保留新窗口查找能力。
- **验证脚本隔离不足**：C原脚本先打开页面再mock，升学页可能在mock前请求模型，且未恢复种子。现在待测页面启动前接管请求、存储和剪贴板，种子只进内存，finally恢复平台方法。集成项目在app启动时就安装隔离。
- **导航意图边界**：写storage失败仍报告跳转成功；未来时间戳有效；删除失败可能重复消费。补先红后绿回归，失败返回错误或不执行意图。

未改动冻结的业务service、云函数、存储格式或package/锁文件。C越界改动的公共测试与验证脚本由集成人复核：保留tab导航业务断言；目标日脚本同步A的学习聚合页入口，并增加种子隔离与恢复。没有单列纯风格启发式问题。

## Spec

规格轴独立对照[三份任务书与共享约定](../tasks/lingnan-ui-parallel/README.md)、产品规格及ADR-0004/0005，发现并修正：

- 基础规则换方案丢约束、课程入口进入新增模式、tab使用旧时间，均与上述规范轴各自核对，未将一轴通过抵作另一轴通过。
- **今日无课误报未导入课表**：原实现把 `brief.hasCourses`（只表示今天的课程）当成全课表存在性。现分别判断全表为空与已有课表的无课日；读取失败独立显示。
- **空闲行误进课程编辑**：时间线统一绑定事件，空闲key被当成课程id。现忽略空闲行，保留实际课程跳转。
- **练习记录漏复制未返回反馈的原答**：原实现要求原答和反馈同时存在。现保留已提交的session.draft；只复制真实返回反馈，缺失反馈明确显示尚未返回，不生成下一轮内容、不写云端。

限定周次变更继续使用原服务端协议，确认前不写课程；部分失败重试及整项撤销的业务测试保留。AI先整理约束、用户确认、规则排程；计划仍只存本机，不计正式课程。没有恢复失物招领入口。
