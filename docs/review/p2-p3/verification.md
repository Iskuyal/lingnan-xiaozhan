# 验证证据

本文档汇总 P2 / P3 的验证命令、实测数字与证据位置。原始记录与截图见 [docs/evidence/p2-p3/](../../evidence/p2-p3/README.md)。

## 一、命令与结果

```powershell
npm run typecheck   # 通过：小程序（tsc --noEmit）+ 云函数（cloudfunctions/tsconfig.json）
npm test            # 43 项全过
npm run verify:wechat   # 开发者工具点击验收：10 项全过
```

`npm test` 构成（43 项）：

| 类别 | 项数 | 内容 |
| --- | --- | --- |
| P1 基础 | 4 | 首页入口与跳转、来源复制反馈、状态页返回、构建清理旧产物 |
| 部门（P2） | 10 | 列表/详情渲染、缺失文案、未知 id、空列表、返回、字段完整性 |
| 资讯解析 | 12 | 真实片段驱动的条目与正文解析、署名行剥离、去重、容错分支 |
| 资讯服务与页面 | 14 | 字段映射与查询参数、空 id 不请求、云开发不可用报错、页面四态与重试、复制链接、返回 |
| 云函数与构建 | 3 | 入库字段契约、云函数产物与 `cloudfunctionRoot`、解析逻辑不进小程序包 |

`npm run verify:wechat` 的 10 项检查：学校名称、部门入口与返回、部门列表（名称与校区）、部门详情（介绍/联系方式或缺失/动态或缺失）、未知部门未找到状态、课表入口与返回、直接进入部门列表后返回首页、直接进入课表状态页后返回首页、资讯列表条目与标题、资讯详情标题/正文/复制入口。

验收环境：微信开发者工具 2.02.2608070、真实 AppID、基础库 3.17.2、模拟设备 iPhone 12/13 (Pro)、`realDevice: false`。

## 三、独立复核（不只是相信实现者的自述）

以下核对不是由写代码的人自证，而是拿到原始材料后另行比对：

1. **部门名录**：下载官网表格图片并逐行核对 5 个组织名称、下设部门、成立时间，与代码数据完全一致（含原文「宣秘团」写法与「红小荔」志愿服务队）；同时确认该表格确无联系方式列与校区列，「缺失」判断成立。
2. **解析器对实时页面**：用编译后的解析模块对**实时抓取**的列表页与文章页（而非提交的 fixture）运行，条目数 10 条/页、标题日期正文与原文一致，导航链接未混入条目。
3. **幂等性**：连续两次同步同一栏目，第二次 `inserted: 0`、集合条数不变。
4. **权限**：从客户端直接写公开集合被拒。

## 四、验收中发现并修复的三个问题

| 问题 | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| WXSS 注释提前闭合 | 开发者工具报 `编译 .wxss 文件错误` | 注释里写了 `.status-*/`，其中 `*` 紧跟 `/` 构成 `*/`，注释提前结束，后续文字被当作样式内容 | 改写注释；新增 `tests/wxss.test.cjs` 守卫（注释提前闭合、花括号平衡） |
| 目录形式的模块引用 | 运行时报 `module 'services/news.js' is not defined` | 微信模块解析**不做** Node 式的目录 `index` 回退，`require('../../services/news')` 找不到 `services/news.js` | 写全为 `.../services/news/index`；新增 `tests/miniprogram-modules.test.cjs` 守卫（按微信规则校验产物中每个 `require` 都能解析到具体文件） |
| 官网 403 | 云函数抓取失败 | 官网拦截缺少浏览器特征的请求（本机 curl 正常） | 补充浏览器请求头；错误信息带上响应片段 |

前两个问题都只能在开发者工具中暴露：Node 不编译 WXSS，且 Node 会自动回退到目录 `index.js`。这也说明「命令行全绿」不能替代开发者工具验收。

## 五、工具注意事项（会再次遇到）

`npm run build` 会清空并重建整个 `dist`，开发者工具的**自动热重载**在连续重建后可能残留旧状态，表现为「报错引用的是旧文件内容」或「文件明明存在却说未定义」。解法：

```powershell
& 'D:\微信web开发者工具\cli.bat' cache --clean compile --project 'F:\VibeCoding\wx-match\dist'
```

随后重新打开项目以强制一次全量编译。此现象已在 README 与 [验证记录](../../evidence/p2-p3/README.md) 中记录。
