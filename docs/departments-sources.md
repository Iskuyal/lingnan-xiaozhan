## 未采用为部门内容的来源及原因

- [团委架构](https://lnc.edu.cn/tw/sygk/yjtw) 中的「二级院团组织」图片是院级**团组织**表格，列为组织名称、团委书记、所在校区、办公地点，共 10 行（含清远校区 8 行、广州校区 2 行）。它是团组织架构，且含个人姓名，与「学生组织」名录不是同一类别；P2 只录入学生组织，故不纳入，仅在此记录其存在与字段。
- 同页「团委成员」图片为团委人员信息，未作为部门内容。
- 学校行政部门（学生工作部、教务处、保卫工作部等，见官网「党政机构」导航）不属于学生组织，未录入。
- 官网「社团风采」栏目涉及大量学生社团（如岭南龙狮协会），是社团活动报道，不是学生组织名录；社团名单未在任何公开页面上以名册形式出现，故不臆造社团清单。

## 已知矛盾与不确定项

- 「我为同学做实事｜“医”心同行，“器材”护航」一文写作“校学生团委器材部”，而「学生组织」表格把器材部列在校学生会下。两种说法都来自官网，本文档保留矛盾，未擅自取一；该文章未作为任一组织的动态收录。
- 「学生组织」页面正文是图片，无法用文本检索确认；若官网后续更新图片，本地内容不会自动跟随，需要人工重新核实（本地数据随包提供，不依赖云环境）。
- 转录自图片的文字存在被误认的可能，本次已用像素核对字符数，但仍建议在微信开发者工具中对照官网图片查看一次。

## 2026-09-18 复核与动态重编排

起因：负责人认为官网的部门信息已经过时，要求改用 2025-2026 区间的信息流重排部门内容。本轮先验证「是否过时」，再重排动态。

### 复核方式

遍历团委与学院新闻共 20 个栏目列表（团委概况、团委资讯、思想引领、组织建设、社区实践、校园文体、创新就业、学院新闻各子栏），汇总 393 条去重条目；对其中 ID ≥ 20500 的 237 篇候选抓取正文，按组织关键词检索。因官网 WAF 限速（见下），实际取到正文 79 篇，全部为 2026 年发布。

### 结论一：组织名录没有过时，介绍文字可以继续用

2025-2026 学年第一学期的《学生干部述职大会》报道（2026-03-10，`content_27039`）在正文中逐一列出出席述职的组织与部门：

> ▲校团委秘书处 ▲校团委组织部 ▲校团委宣传部 ▲校团委广播台 ▲青年志愿者联合会 ▲学生社团管理部 ▲退役军人事务服务站
> ▲校学生会文娱部 ▲校学生会学创部 ▲校学生会体育部 ▲校学生会器材部 ▲校学生会权益部

这与「学生组织」表格图片的记载**逐项吻合**：校学生团委 4 个直属部门（秘书处、组织部、宣传部、广播台）、校学生会 5 大部门（权益部、文娱部、器材部、体育部、学创部）。因此 5 个组织的名称、隶属与下设部门在 2025-2026 学年仍然成立，二轮未改动名录与介绍文字。

首轮记录的「器材部归属」矛盾仍未解决，本轮无新证据。

## 2026-09-26 第三轮：2025-2026 区间全量浏览

起因：二轮只取到 79 篇正文且全部是 2026 年发布，判断依据偏薄。本轮按「先把 2025-01-01 之后的条目**列全**，再逐篇取正文」做，把区间内可归属学生组织的文章一次摸清。

### 方法

- **枚举**：抓团委站与学院新闻站共 **24 个栏目**的列表页（含团委资讯 4、思想引领 5、组织建设 3、社区实践 3、校园文体 2、创新就业 2、学院新闻 5），逐页翻到 2025-01-01 之前为止。
  - 三种列表模板都覆盖（`list-intro` / `newsList` / `picList`）。**判据用栏目路径**（条目 href 必须形如 `<栏目路径>/content_<数字>`），而不是容器 class——`picList` 模板没有容器 class 可用，且这样能天然排掉顶部导航里同样形如 `content_NNNNN` 的外栏目链接。
  - `picList` 模板（团委焦点新闻、思想引领、组织建设、社区实践、校园文体、创新就业均为该模板）**列表页不带日期**，改用文章 ID 定界：实测 `content_20821` = 2024-12-25、`content_22115` = 2025-03-31，故 2025-01-01 落在 ID 20900 附近，取 20800 作停止阈值。
- **取正文**：对区间内**全部**条目逐篇抓正文并提取发布日期。限速 1.4 秒/请求（官网 WAF 红线，见下），近千篇为长跑，脚本每 25 篇落盘、重启时按 URL 跳过已抓，可中断续跑。
- **归属判据**：沿用本页既有标准——**正文里写明该组织参与或负责**才算该组织的动态；关键词命中后另输出命中句供人工复核。

产出（`artifacts/` 不入库）：`list-2025-2026.json`（998 条）、`bodies-2025-2026.json`（998 篇）、`org-articles.json`（67 篇）、`summarize.cjs`。
