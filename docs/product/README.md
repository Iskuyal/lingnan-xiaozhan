# 产品定位与边界

`wx-match` 是 AI 微信小程序开发挑战赛项目的仓库代号，正式作品名称待定。首版面向广东岭南职业技术学院学生，以公开校园信息和学生自行导入的个人课表为基础，提供可核对、有失败降级的 AI 能力。

## 已确认的产品基线

- **服务对象**：普通学生；学生组织是部门资料展示的对象，首版不做部门管理后台。
- **已有功能方向**：首页、学生部门、官网资讯、导入制课表；三个 AI 落点为部门问答、课表图片识别、课表助手。
- **导入方式**：学生提供教务导出的 Excel 或课表截图，核对后保存；允许独立手工增删改，不接入教务账号。
- **信息原则**：使用可追溯公开来源，标明校区及资料缺失；不把模型生成内容当作官方信息。
- **平台与演示**：原生微信小程序；本次参赛走开发者工具「预览」真机演示路径，不把认证、备案、体验版或正式发布写成已完成。
- **视觉基线**：岭南红与金色，来源见 [学校资料](sources/school.md)；当前设计规则见 [设计目录](../design/README.md)。

以上是产品边界，不是验收结果。代码、云端部署与真实效果以 [项目状态](../status.md) 为准。
