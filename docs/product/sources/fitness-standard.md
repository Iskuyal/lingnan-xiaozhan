# 体测标准与来源核验（2026-09-29）

本文件是 [Issue #89](https://github.com/Iskuyal/wx-match/issues/89) 的成果之一：核验《国家学生体质健康标准》
适用版本、适用群体与评分表原始数据，供 [Issue #92](https://github.com/Iskuyal/wx-match/issues/92)
（体测估算器）引用。**本文件只记录核验结果，不代表学校实际采用的规则已经核实。**

## 一、结论（先说能不能用）

| 问题 | 结论 | 依据 |
| --- | --- | --- |
| 适用版本 | **《国家学生体质健康标准（2014年修订）》，教体艺〔2014〕5号，2014-07-07 印发**，至今仍是现行版本 | 教育部官网通知页 + 通知附件原文；2025 年的新文件未修订评分表（见下） |

| **学校实际采用规则** | **未能核实**：官网首页与教务处（`lnc.edu.cn/jwc`）都没有校历/体测栏目，未见学校公开的体测实施办法 | 2026-09-29 抓取；因此估算器必须写明「以学校公布结果为准」 |

### 2025 年新文件是否改了评分表

**没有。** S4 的原文只提出「认真实施国家学生体质健康监测制度」「实施大学生体质提升专项行动」
「高校可积极探索在学生毕业前颁发体质健康证书」等要求，**未宣布修订或废止 2014 年标准**，
也没有给出任何新的评分表。因此估算器只依据 S1/S2（2014 年修订版），并在界面上标明版本。

## 三、评分表数据的抽取与校核

数据文件：[`docs/reference/fitness-standard-2014-tables.json`](../../reference/fitness-standard-2014-tables.json)
（实现引用的 TS 模块是 `miniprogram/services/fitness/standard.ts`，与它同源）。

抽取与校核过程（可复现）：

1. **主来源 S2**：`curl` 下载官方 .doc，本地按 Word 97 的文本流抽取正文（不把文件上传到任何第三方解析服务），
   单元格以 `\x07` 分隔、空单元格充当行分隔符，按「等级 → 单项得分 → 各省份/年级组成绩」的顺序取行。
2. **校核来源 S3**：把 HTML 里的制表位还原成列，逐行取每个分数档的最后两列（大学一、二年级 / 三、四年级）。
3. **逐条比对**：两源重叠的单元格**全部一致（0 处不一致）**。
4. **一致性检查（写在生成脚本里，可复跑）**：每张表分数档唯一且降序；高优项（肺活量、坐位体前屈、立定跳远、
   引体向上、仰卧起坐）成绩随分数降低而单调不增，低优项（50 米跑、1000/800 米）单调不减——全部通过。
5. **缺口补齐**：坐位体前屈的 74~60 档在 S2 的文本流里被截断、在 S3 里丢了负号，最终值由 S3 的粘连文本解出，
   并用等差规律复核（男生相邻档差恒为 −1.4 厘米、女生恒为 −1.3 厘米，与上下档衔接一致）。

> 抽取脚本与原始 HTML/.doc 属中间产物，未入库；复核时按上面的步骤重跑即可得到同样的表。
> 若需要脚本本身，向维护者索取 `.scratch/` 下的生成脚本。

## 五、缺口与冲突（这些都写进界面说明，不替学生猜）

1. **BMI 合并单元格纠错（2026-09-30）**：09-29 文本抽取把「超重」行空白误读为原表未给分。
   表 1-1 / 1-2 中「低体重」和「超重」的单项得分为同一个纵向合并单元格，均为 **80 分**。
   已用[标准 PDF 第 1 页](https://tyb.lzjtu.edu.cn/__local/B/50/74/DD7A8CA37D3025F81EC155813B3_B90C8599_120B57.pdf?e=.pdf)
   看版式复核，[留档截图](../../review/new-updates-2026-09-30/bmi-table.png)可查。该证据纠正 BMI 一项，不声称全表重新核验。
2. **低于最低档（10 分档）按 0 分计**：原表最低档是 10 分，表外没有更低档。这一条是**估算器口径**，
   不是标准原文；已写在结果说明里。
3. **学校实际采用规则未核实**：学校是否按国家标准执行、是否有额外补测或折算规则，没有查到公开依据。
   因此估算结果一律标注「不是学校正式成绩」。
4. **免测/缓测、补测、毕业成绩折算**（标准原文第 8~10 条）不在估算器范围内，界面不提示这些结论。

## 六、更新责任与核查频率

| 事项 | 责任人 | 最低核查频率 | 触发条件 |
| --- | --- | --- | --- |
| 标准是否被修订/替代 | 项目维护者 | **每学年一次**（9 月）或提交前 | 教育部发布新文号、媒体报道修订 |
| 评分表数值与官方附件一致 | 项目维护者 | 每学年一次 | 上条触发时 |
| 学校是否公开体测实施办法 | 项目维护者 | 每学期一次 | 学校教务处/体育部发布新文件 |

## 七、继续 / 停止建议

- **继续**：2014 年修订版的大学组评分表来源明确、数值可逐条复核，估算器可以只在本地做确定性计算，
  不接 AI、不上传个人数据，适合进首版演示。
- **按现状交付的边界**：界面上必须同时出现「标准名称与版本」「适用年级组」「这是估算分、不是学校成绩」
  「BMI 超重按原表计 80 分」「低于最低档按 0 分」五句话，缺一句就算验收不合格。
- **不要做**：不预填或猜测学校体测时间、不引用未经核实的学校实施办法、不把估算分写成「合格/不合格」结论。
