## 解析依据（选择器与噪声）

列表页（`/xyxw/xydt`）：

- 条目容器：`<ul class="list list-intro">`，每条为其中的一个 `<li>`。整页 `class="tit"` 出现 51 次，其中只有 10 次在列表容器内；顶部导航 `div.topLink` 也用 `<a class="tit">`（含 `href="/xxgkw/xyjs/xxzcjzd/content_17924"` 这种同样形如 `content_<ID>` 的链接），因此**必须先定位列表容器再取条目**，否则会把「学院章程」等导航链接当成资讯。
- 标题：条目内 `<div class="title">` 下的 `<a class="tit" href="…" title="…">`；`title` 属性与锚文本实测一致，解析时优先用 `title` 属性、回退到锚文本。
- 日期：条目内 `<div class="con">` 下的 `<span class="date">YYYY-MM-DD</span>`。实测第 1、2、60、120、126 页的条目数与 `span.date` 数量完全相等（10/10/10/10/2），**未发现缺失日期的真实样本**；缺失日期属于容错分支，用裁剪过的真实片段验证，证据见 `tests/news.test.cjs`。

文章页（`/xyxw/xydt/content_<ID>`）：

- 标题：`<article class="article">` 内 `<h1 class="title">`。整页 `class="title"` 出现 8 次（导航下拉 `div.con > div.title`、分享区、页脚二维码说明），`<h1>` 共 2 个（`h1#logo` 与文章 `h1.title`），因此按钮是 `h1.title` 且需注意区分 `h1#logo`。`h1.title` 内含空的 `<div class="sub-title">`，解析时截断该节点。
- 日期：`div.article-hd > div.meta` 内的 `发布时间：YYYY-MM-DD HH:MM:SS`。回退依据：`<meta name="PubDate" content="YYYY-MM-DD HH:MM" />`（实测 7 篇文章均存在且与 `发布时间` 一致）。
- 正文：`<div class="article-content"> … <div class="article-fd">`，边界标记 `article-fd` 后紧跟分享按钮脚本区。另有 `<!-- 正文内容 S -->`、`<!-- 正文内容 E -->` 注释，但 `E` 在 `</article>` 之后、包含脚本，**不适合**作为正文右边界。
- 结构稳定性：抽查 2014/2023/2026 共 9 篇文章，`h1.title`、`div.meta`、`div.article-content`、`div.article-fd` 均恰好各出现 1 次。
- 正文含 `<img>`（图片 URL 为站内相对路径）、`&nbsp;` 实体（实测最多 16 处/篇）。当前只提取纯文本，**不提取图片**：远程图片域名需要在有 AppID 的小程序后台配置 downloadFile 合法域名，当前不具备该条件。
- `<title>` 形如 `标题_校园动态_学院新闻_广东岭南职业技术学院`，可作为标题的最终回退，需截掉 `_校园动态_学院新闻_…` 后缀。

## 解析的脆弱点

- 稳定字段：列表条目的 `href` / `title` 属性、`span.date` 文本、文章 `h1.title`、`发布时间` 文本、`div.article-content` 容器，在 2014–2026 的模板中一致。
- 依赖 class 名（`list-intro`、`tit`、`date`、`article-content`、`article-fd`）与「发布时间：」文案；官网改版会让解析返回空值（不抛异常，页面显示空态或缺失提示）。
- 标题回退用 `<title>`「截掉后 3 段下划线分段」；若标题自身含下划线可能被多截。实测第 1 页 51 个 `tit` 标题都不含下划线。
- 标签剥离使用 `<[^>]*>`：属性值里如果出现 `>` 会提前结束标签匹配。抽查 13 个真实页面的属性值，未发现含 `<` 或 `>` 的情况（正文图片的 `alt` 里出现过 Windows 路径，不含尖括号）。
- 日期只识别 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY年MM月DD日`；其他写法返回空字符串，页面显示「日期待核实」。实测 126 页列表与 13 篇文章都是 `YYYY-MM-DD`。
- 正文里的 `<img>` 只保留其说明文字段落，图片本身与附件（PDF/Excel）不提取。
- 未处理：相关文章推荐、视频、列表页的「共 N 条 / 共 M 页」分页信息（本轮只解析条目，分页留给 P3-2）。

## 去重键与标识

- 去重键：**原文绝对 URL**（`https://lnc.edu.cn/xyxw/xydt/content_<ID>`）。同一 URL 重复出现时保留首次出现的条目，顺序不变。
- 条目 ID：原文 URL 的最后一段路径（如 `content_32118`），用作页面间传参。同一篇文章在不同栏目/分页下 URL 相同，因此 URL 与 ID 一一对应。

## 随包内容快照（P3-1 临时数据源）

云环境不可用，列表与详情页当前读取**随包提供的真实内容快照**：

- 来源：`https://lnc.edu.cn/xyxw/xydt` 第 1 页 10 条，及其文章页正文。
- 抓取日期：2026-09-17；快照文件 `miniprogram/services/news/snapshot.ts` 的头部注释记录了来源 URL 与生成方式。
- 生成方式：用本仓库编译后的解析模块（`dist/services/news/parse.js`）解析当日 `curl` 抓取的原始 HTML，把结果写入快照文件；原始整页 HTML 未入库，只有裁剪后的 fixture 入库。
- 该快照是**静态数据**：不会随官网更新，没有云端读取、没有写入权限校验、没有失败重试。
