# Triage labels

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待负责人评估和分流 |
| needs-info | needs-info | 缺少必要信息，等待补充 |
| ready-for-agent | ready-for-agent | 规格充分、验收明确，可交给 Agent 执行 |
| ready-for-human | ready-for-human | 需要人的决策、资源配置或操作 |
| wontfix | wontfix | 已决定不处理，需记录原因 |

使用上述标签的原始字符串；每次分流替换过时标签，保留一个当前分流状态。Issue 的关闭状态表示任务结束，标签不代替验收证据。
