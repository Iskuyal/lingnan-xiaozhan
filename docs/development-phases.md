## P4：课表（已改为导入制，2026-09-18）

**原 P4-A「教务登录接入调研」已取消**，不是未完成而是目标变更：课表改为由学生自行导入（教务系统下载的 Excel，或课表截图识别）。依据与约束见 [开发规格](development-spec.md) 的「教务接入」一节。

### P4-B 课表导入与 AI 助手

成功路径：进入课表 → 选择导入方式 → Excel 从聊天记录选文件 / 截图拍照识别 → 校对识别结果 → 保存课表 → 查看当前周 → 切换周次 → 用自然语言查阅与增改 → 退出后重进数据仍在。

验收覆盖：单周、双周、多时间段课程、无课日期、**Excel 解析正确性**、**截图识别准确率与人工校对路径**、**不同用户课表隔离**、导入失败的明确提示。

待定的范围决策：Excel 模板适配到哪种版式、截图识别失败时如何引导、课表是否支持手工增删改（AI 之外的表单入口）。
