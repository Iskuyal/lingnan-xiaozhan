# ADR-0005：模型整理学习约束，确定性规则安排时段

日期：2026-11-11。状态：负责人已确认方向和界面，本地、原生固定响应和新授权的单次真实样例均通过。关联 [Issue #146](https://github.com/Iskuyal/wx-match/issues/146)。

## 背景与方案

原学习计划只有有限正则，无法稳定识别“半小时”“一周三回”“周四没空”等自然表达。负责人选择升级为AI理解约束、规则校验排程。

让模型直接排日期和课程会把空档、教学周与时间计算交给不可重复的文本输出。选定模型仅产出约束草稿，用户核对后由既有排程器安排。原规则入口保留；不再忽略未理解的限制或静默放宽超范围输入。

## 决策

1. 复用既有AI网关的chat，业务标记 `study-plan-intent`。用户消息只含目标名称与本次情况，固定系统协议解释结构；不将整份课表、教师、地点或日期放进模型上下文。输出上限900token，沿用原审核与配额，不改云端配置。
2. 输出包含每段上限、每周段数、弱项、不可用星期及上午/下午/晚上。默认参数明确标注；数值、枚举、未知字段、连续原话依据不合法时整份拒绝。无法处理或矛盾的情况先澄清，不替用户选择较宽松条件。
3. 约束草稿不是已保存计划。用户确认后再次读取课表，规则接收已校验的readout，不能再被有限正则覆盖；日期、过去时段、课程冲突和时长继续由规则检查。
4. 上午/下午/晚上沿用1–4/5–8/9–12节。每段上限支持15–180分钟、每周1–14段，是当前产品输入范围，不代表学习效果结论。未填作息不推断具体钟点。
5. 换排法只变规则排程，不再请求模型；只轮换实际可用的星期和空档，相同结果明确反馈。输入或目标变更、页面退出使旧请求失效，旧回复不能回填。
6. 保存增加可选来源与原话依据，旧计划按规则来源恢复；AI来源若缺少匹配依据，按现有脏数据契约拒绝恢复，不伪造AI来源。已保存计划仍只在本机，重开不调用模型。

## 影响与验证

不需要新增云函数或模型供应商。调用仍受既有内容审核、日/分钟额度和月度预算约束。解析输出验证不等于语义100%正确，原话引用也不证明解释一定正确，因此保留用户核对步骤。

本期未加入打卡、自动重排或精确钟点偏好。全量918项、类型检查与新路径原生固定响应通过；另获新的单次许可后实际解析与规则验证通过，约11.3秒，课程未改写。两类证据不互相代替；本轮单次真实许可已使用，不自动复用。
