# 02：首页最近资讯入口与列表逐页加载

**What to build:** 学生从首页就能看到最近几条校园资讯、并进入完整列表；列表往下翻能持续加载更早的内容，加载中、失败可重试、已无更多这几种状态都能区分。用云端现有的 10 条数据即可演示完整路径，不需要先扩大抓取范围。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 首页展示最近若干条资讯，含真实标题、发布日期与来源
- [ ] 首页有进入资讯列表的入口，且不与现有「学生部门」「我的课表」入口冲突
- [ ] 列表逐页加载：加载中 / 有数据 / 空 / 读取失败可重试 / 已无更多，五种状态可区分
- [ ] 相同发布日期下顺序稳定；连续加载无重复条目、无遗漏条目
- [ ] 加载下一页失败时保留已加载条目，不清空；重试成功后不重复追加
- [ ] 分页读取全部走云端数据库，不引入随包静态快照
- [ ] 列表与详情之间可往返，直接打开详情后也能返回
- [ ] `npm run typecheck`、`npm test` 通过；开发者工具验证首页到列表到详情及分页路径
