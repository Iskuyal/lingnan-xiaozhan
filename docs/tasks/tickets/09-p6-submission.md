# 09：P6 参赛材料与包

**What to build:** 把已完成的校园工具交付成可提交的参赛作品：核心流程在真机上能稳定演示，七项说明材料完整无占位符，参赛包可复现且不含密钥，并实际提交拿到回执。

**Blocked by:** 02（首页资讯入口与分页）、04（资讯同步范围）、05、06、07（AI 三落点）；另外依赖负责人确定**正式作品名称**及交付前的校内收口时间与材料交接方式。01、03 通过 AI 功能票间接依赖。

**Status:** needs-info（阶段级清单；依赖落地后按实际范围细拆，补全验收与证据要求再转为 ready-for-agent）

- [ ] 回归首页、部门、资讯、课表与 AI 的核心流程，修复阻断问题
- [ ] 在真机上记录环境、结果与演示视频；配置体验版或说明其阻塞原因
- [ ] 七项说明材料完整（项目说明、小程序与 AI 能力、创新点、技术实现、成果展示、历史说明、落地规划），无未说明的占位符
- [ ] **第三方来源如实说明**：官网资讯为转载性质、AI 走第三方中转，都按实际写明；不隐瞒非官方渠道
- [ ] **AI 能力融合的论据来自 05 与 06**（多模态识别、自然语言到结构化变更），不要用部门问答充当核心价值——那里语料只有 5 个组织
- [ ] 源码对应明确的 commit/tag，按说明可安装、配置、运行
- [ ] ZIP 命名符合官方规则、体积合规、**不含生产密钥、私人信息、依赖目录**
- [ ] 按学校要求交付参赛包，跟踪统一上报并保存最终提交成功凭证；记录交接与提交时间、包名及对应 Git 版本
- [ ] 交付前确认学校统一上报的校内截止时间（早于组委会的 11-18）
