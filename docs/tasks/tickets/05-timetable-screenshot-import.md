# 05：课表截图识别导入与校对

**What to build:** 除了 Excel，学生还可以直接拍课表或从相册选一张课表截图，由多模态模型识别成结构化课表；识别结果先给学生逐项确认和修正，确认后才保存。保存后复用 03 已有的周课表展示与周次切换。

这一票是「AI 在本产品里真实不可替代」的第一处：课表截图版式千变万化，规则解析写不完，多模态是唯一务实解。

**Blocked by:** 01（AI 服务端基础设施，已合入 main）、03（课表存储与展示，代码已合入、云端部署未完成）。识别失败后的引导方式已于 2026-09-18 确定：**重试 + 引导 Excel 导入 + 手工录入兜底三者都可走通**（手工编辑已纳入首版，由 03 交付）；写入 [开发规格](../../development-spec.md)。

**Status:** in-progress（代码与本地测试完成，2026-09-18；按 01 已发布的 vision 契约与 03 的确认/保存链路实现界面）。**2026-09-19：用三张真实课表截图跑通端上链路的前半段**（入口 → 压缩判定 → 文件头判格式 → 上传 → 内容安全 → 模型），**并实测了模型不可用时的失败出口**；**但模型这一环在当前配置下不通**：三条样本 + 一张 570 字节合成小图全部在 8000ms 处超时（`failureClass=model_unavailable`），因此**字段准确率评估无法执行**（模型一个字段都没返回），本票仍为 in-progress。逐项依据与复测方式见 [P5-B 验证记录](../../evidence/p5-b/README.md#ticket-05-课表截图识别端上真实截图验收2026-09-19未通过模型这一环)。
