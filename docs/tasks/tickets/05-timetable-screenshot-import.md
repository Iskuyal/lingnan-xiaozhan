# 05：课表截图识别导入与校对

**What to build:** 除了 Excel，学生还可以直接拍课表或从相册选一张课表截图，由多模态模型识别成结构化课表；识别结果先给学生逐项确认和修正，确认后才保存。保存后复用 03 已有的周课表展示与周次切换。

这一票是「AI 在本产品里真实不可替代」的第一处：课表截图版式千变万化，规则解析写不完，多模态是唯一务实解。

**Blocked by:** 01（AI 服务端基础设施）、03（课表存储与展示）；负责人确认识别失败后的引导方式及独立手工录入是否纳入，见 [开发规格](../../development-spec.md)。

**Status:** ready-for-human（降级范围确认后转为 ready-for-agent，仍须等待 01、03）

- [ ] 学生可拍照或从相册选课表截图
- [ ] 图片**先过内容安全检测**再送模型；被拒时给出可理解的提示而不是静默失败
- [ ] 识别结果以**可编辑**的形式呈现，学生逐项确认或修正后再保存
- [ ] 识别部分失败时明确标出未识别内容，允许重试；已识别结果可人工校对。独立手工录入是否作为兜底，按确认后的范围补齐验收
- [ ] 保存后复用 03 的周课表展示与周次切换，不另建一套
- [ ] 用**真实课表截图**验证并记录识别准确率，样本中至少包含一个识别失败的案例
- [ ] 模型不可用时明确告知并引导到 Excel 导入；若决定纳入独立手工录入，则同时验证 Ticket 03 提供的入口
- [ ] `npm run typecheck`、`npm test` 通过；开发者工具验证截图到校对到展示的完整路径
