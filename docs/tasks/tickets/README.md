## 拆分时的三个判断（供回溯）

1. **03 先于 05/06，且不依赖 AI。** Excel 解析是确定性的，先做通就能把「课表数据模型 + 展示 + 周次 + 用户隔离」这套最不确定的部分验证掉；万一 AI 线出问题，课表本身已经能演示。
2. **01 是唯一的 prefactor。** 05/06/07 共用「模型调用 + 内容安全 + 失败降级」，先建一次比三处重复造好。内容安全是微信硬要求，集中在这里而不是散在三票里。
3. **AI 的价值论据在 05、06，不在 07。** 部门问答语料只有 5 个组织、约两千字，撑不起「AI 能力融合」20 分。这一点写在 07 和 09 里，避免将来写材料时误判。
