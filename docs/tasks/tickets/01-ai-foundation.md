# 01：AI 服务端基础设施

**What to build:** 产品里任何一个 AI 功能调用模型时，都走同一套服务端管道。学生在任意 AI 入口提问、上传图片时，系统能稳定地调用外部大模型、对输入输出做内容安全检测、并在模型不可用或内容被拒时给出可区分的失败而不是白屏或假成功。密钥只在云服务端，不进入小程序包。

这一票不面向最终用户界面，但它是 05、06、07 三票的共同前置——那三处都需要「调模型 + 过内容安全 + 失败降级」，先建一次，避免每处重复造。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 云函数侧提供统一的模型调用入口，密钥来自云函数环境变量，不落在代码、数据库或小程序包里
- [ ] 单次调用有明确超时边界，超时后返回可识别的失败，不无限挂起
- [ ] 每次调用记录耗时与用量，可查询累计用量（用于成本上限的判断）
- [ ] 文字内容安全检测可用；违规内容被拒绝并返回可与「调用失败」区分的结果
- [ ] 图片内容安全检测可用，接口与文字检测分开
- [ ] 失败结果能区分三类：「模型不可用或超时」「内容被安全策略拒绝」「额度或配额用尽」
- [ ] 端到端验证：一句测试文本经模型返回结果，全过程无密钥外泄（检查小程序包与数据库）
- [ ] 第三方中转不可用时，调用方拿到的是可处理的错误而不是未捕获异常
