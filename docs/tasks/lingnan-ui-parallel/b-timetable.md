- 周/日课表：保留切周、管理、助手与完整12节入口；节次轴在横向滚动区之外，周末、晚课、单节/跨节、长名称、多课冲突均可读。3–8节只是样例紧凑范围，不能漏掉实际存在的早晚课。

- 课程详情/编辑/删除、学期与作息：可编辑、可选择和只读值区分；缺作息不预置钟点。删除与返回清楚说明影响，失败保留输入。
- 助手与通知：沿用模型解析和程序校验；原通知可改回再核对，确认前不写。限定周次的时间/地点变更不扩大到其他周，幂等重试和整项撤销保持；部分成功显示每项实际状态及待重试的具体改动。
- 保存后留在对应周，并保留课表切周/周日视图/管理，目标课程初始可见且有独立变化标记；不能只给成功toast。学习计划仍与正式课程分开展示，不计课程数。

完成条件：从导入到保存、查询到纠错/确认、限定调课到撤销、部分失败到定向重试均有可运行路径；确认/取消/重复点击不能改变原业务约束。
