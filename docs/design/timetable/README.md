# 课表改版设计图

**这是「界面改动先出设计图」这条约定的第一份产物**（约定本身见 [docs/design/README.md](../README.md)）。
本目录同时是设计评审件与实现的尺寸依据：评审看 `png/*.png`，实现抄 `*.html` 里的数字。

## 为什么要改

现版课表把「能查」做完了，但在手机上读不动：7 列均分后每列只有 41px 宽，课名排两个字就折行；
一门课在网格里只有一个名字，教师、地点、周次全要下到列表里看；没有学期与开学日，所以永远是「第 1 周」；
没有课程配色，45 门课在同一片红金纸上是同一片灰。设计图解决的就是「读不动」和「看不出区别」。

## 做什么、不做什么

**引入**（参考既有课表实现的做法，按本仓库规格自行实现）：

| 能力 | 设计图 | 说明 |
| --- | --- | --- |
| 12 节细网格 + 连堂合并 | 01 | 真实样本只给节次，12 节是节次的自然上限 |
| 课程配色（8 色自动分配） | 01、10 | 同名课程恒定同色，编辑页可改 |
| 学期 / 开学日 / 总周数 | 07 | 有了开学日才知道今天是第几周、本周几号 |
| 今日速查与今日列高亮 | 01 | 正在上 / 下一节 / 今天没课；依赖作息时间 |
| 作息时间（用户自填） | 07 | **不内置任何默认值**，见下方红线 |
| 课程详情弹层 | 05 | 点课块出全量信息与修改/删除 |
| 周次编辑器（起止 + 单双 + 自选周） | 06 | 现版只有一句原文，改不动 |
| 课程管理（多选、批量删除、统计） | 08 | 45 门课要能成批收拾 |
| 导入确认页双视图 | 09 | 列表看细节，课表看落位 |
| 视图切换（课表 / 列表） | 01、02 | 网格负责「一眼」，列表负责「读全」 |

**不引入**：背景图、按日期的临时调课（调课/停课/补课）、多学期切换、订阅消息提醒、
课表导出与分享文件、桌面小组件。这些都不在本次范围内，若要做另开任务。

**保持不变**（现版已有且更该保留）：

- 只按节次展示、**学校作息未核实就不臆造时刻**这条纪律，以及它的实现方式：作息由用户自己填。
- 解析不确定的课程一律「只标记不猜」：待核对用琥珀虚线块 + 列表里的警示行，原文进详情弹层。
- 云开发存储、按 openid 隔离、客户端不直连数据库、导入不写库。
- 岭南红 + 金 + 液态玻璃的视觉方向、琥珀只用于警告、色值只集中在 `app.wxss`。

**红线**：参考项目的名称、标识、文案一个字都不能出现在仓库、产品与参赛材料里；
其代码不得整段照搬。本目录的设计图是按下面的规格重画的，不是它的设计稿。

## 单位与命名

设计图按 **390px 宽**绘制（iPhone 14/15 逻辑宽度）。小程序 750rpx = 屏宽，所以
**1rpx = 0.52px**；`app.wxss` 里以 px 写的值（如 `--glass-blur: 16px`）在图上仍是同值。
写实现时把图上的 px 除以 0.52 换算成 rpx（例：43.7px = 84rpx，10.4px = 20rpx）。

文件：`NN-画面.html` → `png/NN-画面.png`。`_tokens.css` 是令牌（与 `app.wxss` 逐条对应），
`_mockup.css` 是版式与组件。渲染命令：

```bash
node scripts/render-mockups.mjs docs/design/timetable          # 全部
node scripts/render-mockups.mjs docs/design/timetable --only 01 # 单张
```

## 版式规则（实现必须遵守的几条）

1. **列宽自适应**：有课的天均分剩余宽度，没课的天收窄到 22px（44rpx）。
   7 列均分在 390px 屏上只有 41px，课名两字就折行，这是本版最关键的取舍。
2. **课块按高度分级给信息**：≥3 节显示「名称 + 地点 + 教师」；2 节显示「名称 + 地点」；
   1 节只显示名称。名称最多 3 行，超出省略号；完整名称在详情弹层与列表视图里。
3. **同一格多门课**：折叠为堆叠卡，右上角数字角标（全白底 + 金描边，与课程色无关），
   点开是并列清单，不并排挤在格里。
4. **状态语义**：今天 = 列底金晕 + 表头红圆底日期；正在上的课 = 课块金描边；
   待核对 = 琥珀虚线边框 + 琥珀字；手工新增 = 「手工」chip。红只用于品牌与今天，琥珀只用于警告。
5. **时刻的两种世界**：填了作息 → 时间轴显示起止时刻、今日速查条给「正在上/下一节」、
   课块可显示时刻；**没填 → 全链路不出现任何时刻**，只给一行说明与「去填写」入口（03）。
6. **不出现空壳控制**：没开学日就不显示日期区间，没作息就不显示时刻与速查条，
   而不是显示「--:--」这类占位。

## 待拍板（负责人）

1. **课程色板 8 色是否够用**：偏冷的蓝绿紫 + 石墨，刻意避开品牌红与警告琥珀。
   8 色在 45 门课里会重复约 6 次；色只是「分组线索」，不是唯一标识。要更多色可加，但可辨识度会降。
2. **列宽自适应**是否接受「没课的天只剩 22px」。好处是有课的天从 41px 变 60px、课名读得出来；
   代价是周五周六周日的表头只放得下「五 25」。
3. **作息时间是否做**：不做则今日速查、日视图、时刻全部不存在，只剩节次；做则由学生自己填一次。
4. **多学期**本次不做，学期设置只有一条（名称 + 开学日 + 总周数），旧学期数据仍按 semester 字符串保留。
5. **12 节上限**延续云端契约（`MAX_SECTION = 12`），不改。

### 平台能力缺失的导入降级

如果当前微信环境没有 `wx.chooseMessageFile`，导入页留在当前页面并显示系统说明弹窗，提示改用课表截图识别，或返回课表后手工录入；不调用云函数，也不改动课表数据。这是既有导入引导页上的原生系统弹窗，不新增页面版式。
