## 为什么这样画

体测估算最容易出的两个错是「把没填的项目当 0 分」和「把估算分说成学校成绩」。所以：

- **输入区**每项独立成块、单位写在框内右侧，长跑同时接受 `3′42″` 与纯秒数（换算结果实时显示）；
- **结果区**先给总分与等级（只有 7 项都有分时才有），再逐项列出得分；
  没有分数的项目用琥珀色写清原因（原表未给分 / 没填 / 低于最低档按 0 分）；
- 三处固定说明：标准名称与版本、年级组、「这是估算分不是学校成绩、学校规则未核实」；
- **超重不给分**这一条单独用琥珀提示条说明（图 03），因为它会让学生看不到总分。

## 版式规则（390px 画布，1px = 1.923rpx）

- 输入块：内边距 12px、边框 1px `rgba(43,36,34,.14)`；单选 pill 高 44px、选中为品牌红；
  输入框高 44px、字号 15px；提示 11px。
- 结果摘要：左边框 3px 品牌红 + `--paper-shade` 底，内边距 14px；总分 34px/700、等级徽标 11px；
  不完整时改用 26px 的「已计分项目加权标准分」+「暂不给出」文案。
- 明细表：行高 9px 上下内边距，项目名 13px、成绩 11.5px 右对齐（宽 104px）、得分 14px/700（宽 52px）；
  无分时用琥珀色 11px。
- 说明区 11px/行高 1.8；「改一个数字重算」是整宽主按钮。

## 待拍板项

1. **首页入口**：与「校历与考试」并排两格（见 `docs/design/goal-days/05-home-entry.png`）。
2. **是否显示学校规则提示的强度**：现在每次结果都重复三句说明。要不要收成一行「为什么是估算分？」
   的可展开说明，只在首次进入时展开？
3. **「低于最低档按 0 分」的口径**：原表最低档是 10 分，表外没有更低档，本估算器按 0 分计并在说明里写明。
   备选是按 10 分计（更宽松）。这一条需要负责人拍板，因为它会影响学生的估算结果。
