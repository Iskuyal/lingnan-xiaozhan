## 为什么这样画

这张卡的风险不在排版，而在**看起来像有日期**。所以两屏的差别就是「有没有日期」：

- 有官方日期的（四六级考试日）给倒计时徽标、考试日期加粗、来源与公告发布日在卡片底部；
- 没有官方日期的（待公布、仅官方入口、以本校通知为准）**不画日期行**，徽标写清属于哪一类，
  卡片底色更淡，右下角从「复制原文链接」改成「打开发布页 / 打开报名系统」。

「报名」始终单独一行：报名时间由各考点/省考试院自定，混进考试日期会误导（报名可能早已截止）。

## 版式规则（390px 画布，1px = 1.923rpx）

- 页面边距 22px/18px（全局 `.page`）；标题 27px；说明 13px。
- 分组：学校校历 → 四六级 → 计算机等级 → 普通话；标题 16px，右侧条数 11px。
- 卡片：左边框 3px（有日期 = `--brand-deep`，无日期 = 中性灰），内边距 11px 12px，白色半透明底。
- 卡片内：标题 15px/600，状态徽标 10px/700（高 22px、圆角 3px）；
  信息两行 11.5px，键宽 44px；来源区与内容之间一条发丝线，来源文字 10px、复制键 10px/700。
- 有日期的卡片底色 `rgba(255,255,255,.62)`，无日期的 `rgba(255,255,255,.45)`。
