# 独立产品视觉评审

评审版本：`LN-6c774710ba24831b`。评审对象是静态设计提案，依据固定评审提示、最小产品简报及 `review/manifest.json` 所列图像；未读取实现代码、README 或其他评审意见。

## 1. 总体判断

**最强的设计决定：** 将岭南红集中在当前任务、主操作和关键结果上，并通过“草稿 → 本人核对 → 保存”的连续画面，让课表修改和 AI 学习安排的确认责任非常清楚，尤其是 04、09、15–17、39、69、76。

**最关键的不足：** 79 的逐条导入修正页把课程名仅呈现为标题和原文件文字，可修改控件只覆盖地点、星期节次和周次，保存前修正错误课程名的入口尚未在这组设计证据中表达完整。

整体任务表达成熟：今天、课表、学习、校园四个聚合入口有明确的内容职责，首页的下一节课、学习页的目标与本周计划、校园页的资料入口形成各自重点，没有把所有功能压成同等级九宫格。三步进度、红色主按钮、灰色说明区、白色内容容器和青绿色结果状态跨页面延续，页面虽然多，学生不必反复学习操作语法。

品牌表达也服务于任务：拱门图形、岭南红及首页大时间构成可辨认的主视觉，课表使用轻量课程色区分信息，问答页则把强调色交给来源标记和可执行入口。它没有让装饰压过课名、节次或操作，也没有因为 AI 功能而另起一套视觉语言。

## 3. 改进建议

1. **P2｜79 重新核对课程；关联 04、69、76 的“修正”入口。**
   **观察事实：** 79 的完整 390px 和 320px 图中，“英语听说”是标题，原文件表格也显示课程名；可编辑控件只有草稿地点、星期与节次、上课周次，没有看到课程名称的可修改字段或明确入口。
   **用户或视觉影响：** 导入核对是保存前确认数据的主要环节，名称识别有误时，学生看到“逐条修正”却无法从当前设计判断应在哪里改名，容易先把错误名称带入整份课表。这里指出的是设计表达缺口，不能据此断言实际程序禁止改名。
   **具体修改：** 在逐条修正页加入有标签的“课程名称”输入框，明确区分原文件名称与草稿名称；保留地点、星期节次和周次的既有核对关系，确认后在清单中呈现更改后的名称。
   **如何复查：** 补一组“名称识别有误 → 修正名称 → 返回清单”的 390px/320px 静态状态，检查原值、修改值、仍未保存的草稿状态及清单结果是否一致，并确认长名称换行不挤占修正操作。

2. **P3｜68 单字段地点核对页的上下文组织。**
   **观察事实：** 页首副标题、原文件表格和下方只读上下文都重复显示“数据库原理 / 周三第 5–6 节”；再加上双行大标题，320px 完整稿中，仅核对一个地点也形成较长页面，整组确认/取消操作延伸到首屏下方。
   **用户或视觉影响：** 同一个核对任务的说明层级多于输入内容，学生反复核对多条课程时会多读、多滚动，模块节奏也接近介绍页而不是轻量修正页。
   **具体修改：** 保留原文件、地点输入和“只改草稿”的边界说明；将课程与周次上下文合为一行简短摘要，缩短重复的页首说明，降低单字段修正页的标题和留白高度，不缩小来源裁片与输入控件。
   **如何复查：** 在 320×844 与 390×844 视窗检查原文件片段、当前地点及确认/取消操作的阅读顺序，目标是无需为重复上下文滚动，同时保持原文件字符可辨和草稿边界可见。

## 4. 总体评分、置信度与证据边界

**总体评分：8.6 / 10。**
这套静态设计已经形成清楚的学生任务入口、连续的确认流程和统一的视觉身份，尤其在限定周调课、局部重试、资料不足、缺项估算与退出清空这些容易误解的位置表达准确。它距离更出色的执行主要差在导入修正字段表达的完整性，以及少数操作页仍沿用较长的介绍式节奏；这些问题具体、可修，不动摇当前整体结构。

**置信度：较高，限于静态设计范围。** 79 类画面均通过 overview 与 contact-01 至 contact-10 覆盖；额外放大读取完整单图 01、02、04、06、09、11、15–17、19、26、30、31、36–39、43、44、49–52、63–65、67–79；重点查看相应 320px 图，并补看 27、44–48、50、64 的窄屏状态。检查了课表左右滚动的 320/390px 状态、04 的展开课程、15/16/31 的底部状态、69/76 的完整清单尾部、77 的中段与重答尾部，以及 01/02/11/19/36/53/67/71 的关键滚动或选中位置。

48/50 的 320px 附录条曾在完整图初读时未辨认清楚；随后直接截取这两张原图的 y=88–128px 区域放大，均读到“暂缓模块设计附录 · 不新增正式入口”，并与对应 320 逻辑宽度的 DPR3 元素图一致。此项是辨认复核，**未列为缺陷、未据此扣分**；DPR3 元素图没有替代完整画面的布局判断。
