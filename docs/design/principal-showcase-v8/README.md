# 校长审核动画 v8：镜头推近、批注与结果核对

2026-10-10。状态：**自审，待负责人评审**。仅用于展示动画的画面版式，不修改实际小程序页面或业务接口；画面中的手机界面是代码复现的合成示例，不是真机或云端截图。动画已按本版式实现并渲染为[v8候选成片](https://github.com/Iskuyal/lingnan-xiaozhan/blob/864565f16691f0117b69b268433e1a998665b123/docs/competition/principal-2026-10-08/README.md)，实现见[product-demo](https://github.com/Iskuyal/lingnan-xiaozhan/blob/864565f16691f0117b69b268433e1a998665b123/docs/competition/principal-2026-10-08/product-demo/README.md)；成片未整片连续观看，不代表评审通过。

## 为什么改

v7 把手机按 1:1 固定在 1600×900 画面右侧，约占 26% 宽度，界面文字只有 11–16px，投影时看不清；左侧 78px 大标题、三段标签与大片留白又像幻灯片，镜头几乎不动。v7 用左栏「文字特写卡」重复数据来补救，观众仍看不到真实界面上的变化。v8 保持 12 项功能、3 分 54 秒时间轴、合成数据与演示边界不变，只改变镜头与版式：

- 手机随操作**推近**，被操作的区域占满右侧，界面文字 ≥ 22px。
- 左栏只保留章节序号、当前步骤与结果变化；**批注**直接指向手机里被操作的元素。
- 分段进度只占左栏宽度，不压在手机上；演示身份分两层（顶部固定标签 + 底部每项功能的具体说明）。
- 片头用品牌门楼图形，片尾回顾 12 项功能并保留边界声明。

## 不改什么

- 12 项功能、时间轴（234 秒）、合成数据、固定模拟 AI 响应、「非真机录屏」「升学问答效果待独立验收」等边界声明。
- 确认前不写入、取消不改变课表的交互语义，以及 v6.5 PPT/PDF（已冻结）。
- 窄屏浏览器版仍沿用 v6/v7 的纵向重排，不套用镜头推近。

## 待评审

1. 左栏与手机之间在全景镜头下留有约 300px 空档，是否需要用更大的全景倍数（如 1.15）收紧。
2. 结果标签放在高亮框右侧，若课表块靠右可能被画面边缘遮挡，实现时需要按位置自动换到左侧。
3. 片头 6 秒内同时出现品牌、标语与边界声明，是否过满。
4. 设计图由代码手机图拼成，不代表最终帧；连续动效、配音节奏与投影观感仍须看成片。
