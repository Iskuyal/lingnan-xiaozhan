# 课表主页可读性返工

状态：**待评审**（2026-09-26）。三张静态稿已渲染；同一批数字也已落到 `miniprogram/pages/timetable/`，
实现结果见下「实现对照」一节。**待拍板项在最后一节，负责人未拍板前这份稿不算定稿。**

本目录是 `docs/design/campus-refresh/`（2026-09-25 定稿）里课表主页三屏的返工稿：
视觉系统、令牌与课程色板全部沿用那一版，不改品牌红、不改纸白底、不改 84rpx 节次行高与 12 节结构，
只改「真实数据进来之后撑不住」的三处。

## 为什么返工

第一版设计图用的是短样本（课名 7-9 字、地点「崇礼楼 306」）。把开发者工具里已经存在的
**真实课表**（20 周、198 个课块）量过之后，三处对不上：

| 实测 | 第一版设计图假设 | 后果 |
| --- | --- | --- |
| 地点最长 19 字，如 `博雅楼-B604-前端H5创新应用中心` | `40号楼-B310` | 课块地点一行只能放约 4 字，显示成 `40号楼-服装工…` |
| 课名最长 20 字（`毛泽东思想和中国特色社会主义理论体系概论`），198 个课块里 173 个是 2 节块 | 短名 | 课名被截成 `毛泽东思想和中国…` |
| 宽列实测约 55px、可写字宽约 44px | 未量 | 11 字课名要 3 行才排得下，字挤成一团 |

另外两处是代码与设计对不上，不是数据问题：

- **列表视图是空的。** 设计图 `campus-refresh/08-timetable-list.html` 画了列表，`index.wxml` 也一直在渲染
  `view.days`，但 `buildWeekView()` 从来没有产出 `days` 字段——点「列表」得到一页空白。这是本次改动里
  唯一的真 bug。
- **「问问课表助手」是深棕字压在品牌红上。** `button { color: inherit }` 让文字继承了正文色 `#2b2422`，
  对比度约 **2.5:1**（WCAG AA 正文要求 4.5:1）。同一页的 `.seg-item-on`、`.qa-send`、`.sheet-btn` 都显式写了
  `color:#fff`，只有这个按钮漏了。

## 改什么、不改什么

改：

1. 网格留在**页面 18px 边距内**（负责人 2026-09-26 指定，取代先前的通栏）：节次轴 42px → 29px。
   没课的天**收成 32rpx（16.7px）细列**，只写单字星期——原来 48rpx（25px）被反馈「全空还占宽」，
   但当天改成整列不画又被反馈「当天没课就不显示天数了」：**七天必须都在表里**，
   整列消失会分不清「那天没课」和「表被截了」。细列宽度从 1/3 处省下来给有课的天：
   4 天有课时每列 68.75px、5 天 58.8px，可写字宽 55px 上下（原来固定 55.4px／含空白列 62.6px，
   但课块只有 40.8px 可写）。每行从约 3.6 个汉字提到 5 个。
2. 课块文字分级：课名 11px 最多 4 行（2 节块 3 行、1 节块 2 行）；地点最多 2 行；教师只在 3 节以上的高块里出现。
3. 地点在**网格里**缩成「楼栋-房间」（`博雅楼-B604-前端H5创新应用中心` → `博雅楼-B604`）。
   只影响课块显示，列表与详情弹层仍是原文，见 `services/timetable/view.ts` 的 `shortLocation`。
4. 课块不再叠外框，只留 3px 色条 + 浅色底；行线保持中性发丝线。
   **块内文字垂直居中**（负责人 2026-09-26 指定）：连排 4 节的块高 174px，原来是字堆在顶上、
   下面一大片纯色，看着像没渲染完；现在整块居中，高矮块读起来都像一张卡片。
5. 品牌红细线从页头移到「本周课表」分区标题上方（对齐 campus-refresh 的 `20-timetable-week-empty`），
   页头不再同时挂一条线和一个金色小竖条。
6. 头部三行收成两行：`本周 14 门 · 共 50 门课程`；`课表保存于 …` 移到页面底部说明句末。
   日期区间从元信息行挪到「第 N 周」下面，周次与日期读成一个整体。
   **周次行居中**（负责人 2026-09-26 指定）：箭头、周次、日期、课程数在页宽里居中排，
   实测左右各留 74.6px，不再是「几件挤在左边、右边空一大块」。
7. **翻周箭头改用 `view`**：原生 button 自带 184px 内在宽度与水平 `auto` 外边距，页头这一行有空余时
   会把两个箭头推到两头，「第 N 周」孤零零留在中间——实测左右各被推开 37px。选择器也不再撑满整行，
   居中后量测 43 / 105 / 43px，取代 campus-refresh 记的 43 / 254 / 43px（那次只修「选择器宽 0px」，
   没有处理 auto 外边距）。
8. 列表视图按 `campus-refresh/08` 实现：按星期分组（带完整日期与「今天」），行内写全地点与教师，
   行底用纸面中性色、颜色只留在左侧 4px 色条上。修改/删除两键显式定宽——原生 button 带 184px
   内在宽度，不写宽度会把整行挤成两半（列表此前从未渲染过，这个坑是这次才暴露的）。
9. 底部工具区通栏（一条横带 + 发丝线，仍是 campus-refresh 的 `07`/`20` 画法），
   助手按钮补 48px 高、5px 圆角与**白字**。
10. 空态的「手工新增课程」原写 `tt-secondary`，但没有这个类，一直是第二颗品牌红大按钮；
    改回全局的 `.secondary`。

不改：84rpx 节次行高、12 节结构、8 色课程色板、周次/今日速查/退化提示的语义、任何写入路径。

## 版式规则（390px 画布，1px = 1.923rpx）

- 网格：宽 354px（页面 18px 边距内，外框 1px）；节次轴 29px；没课的天固定 16.7px（32rpx，只写单字）；
  有课日等分 `(352-29-16.7×没课天数)/有课天数`——4 天有课时 68.75px、5 天有课时 58.8px。
- 表头高 42px（80rpx）；每节 43.68px（84rpx），块间留 1.56px（3rpx），块左右各留 2.5%。
- 课块：左边框 3px 课程色；内边距 3px 4px 3px 5px；课名 11px / 行高 1.3；地点 9.5px / 行高 1.35；
  内容在块内垂直居中。
- 底部工具区：`margin: 17px -18px 0`，按钮高 44px，助手按钮高 48px。
- 课程色仍以 `miniprogram/services/timetable/palette.ts` 为单一来源，本目录 `_tokens.css` 跟着它走。

## 已知限制

同一门课与另一门课**部分重叠**时（198 个课块里 32 个，16.2%），两块按泳道并排，各占列宽 45%——
有课的天多时只有约 28px，课名只能读到两三个字。合并同格（完全重叠）不会走这条路。这一条是既有
几何规则的固有代价（`view.ts` 的 `assignLanes`，有测试锁住「部分重叠不折叠也不互相压住」），
本次没有改算法；要根治得让泳道在互不重叠的节次上铺满整列。
