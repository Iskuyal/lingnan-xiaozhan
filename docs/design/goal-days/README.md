对应 [Issue #90](https://github.com/Iskuyal/wx-match/issues/90)：学生自己填的考试 / 报名截止 /
项目节点日期，看还剩多少天。这一版**不接云端、不接 AI、不预填任何学校日期**，全部数据存在本机。

## 为什么这样做

`#90` 的价值是「不依赖云开发、AI、学校接口的个人倒计时闭环」，所以数据链路只有一个方向：
学生输入 → 本机存储 → 本机计算。因此本稿刻意不画：账号、同步、提醒推送、学校校历预填。
后两项在 [Issue #91](https://github.com/Iskuyal/wx-match/issues/91) 处理，且必须带来源与核查日。

## 日期语义（实现与测试的唯一口径）

- 日期按 **Asia/Shanghai 的日历日**计算，与设备时区无关：`今天` 由 `Date.now() + 8h` 取 UTC 年月日得到。
- 状态只看「目标日 − 今天」的日历日差 `d`，不看具体时刻：
  `d > 0` 未到期、`d = 0` 今天、`d < 0` 已过期。**同一天永远不出现「已过期 1 天」或「还有 1 天」两种读法。**
- 剩余天数 = `d`（默认）；打开「计入当天」后 = `d + 1`（今天也算一天）。
- **「就是今天」不受开关影响**：把今天算成「还有 1 天」会与当天状态自相矛盾，所以不这么做。
- 非法、空、格式不对（如 `2026-2-30`、`2026/09/29`）一律拒绝保存，不猜、不纠正。

## 版式规则（390px 画布，1px = 1.923rpx）

- 页面边距 22px/18px（全局 `.page`）；标题 27px；说明文字 13px；发丝线 `rgba(43,36,34,.13)`。
- 分组：未到期 / 今天 / 已过期，各带条数；**空分组不画**。分组标题 16px，条数 11px。
- 条目：左边框 3px（未到期金色 / 今天品牌红 / 已过期琥珀 `#c68a32`），内边距 11px 12px；
  名称 15px 600，状态徽标 10px 700（高 22px、圆角 3px），元信息 11px；
  「修改 / 删除」两键各 62px 宽、32px 高（原生 button 有内在宽度，不定宽会挤行）。
- 输入：字段块内边距 12px，输入框高 44px、字号 15px；日期选择行高 48px、值 17px 700；
  开关 46×26px、滑块 22px；提示文字 11px。
- 预览块：左边框 3px 金色 + `--paper-shade` 底，编辑期就显示保存后会看到的文案。
- 悬停态、加载态、失败态仍然按 `docs/development-spec.md` 与既有页面约定处理（图上不画）。

实现时踩到的两个库内限制（写下来省一次返工）：

- **原生 `button` 在模拟器里锁 184px 内在宽度与水平 auto 外边距**：页面 WXSS 写的 `width` / `margin`
  不生效。成对的小按钮（修改 / 删除）因此改用 `view` + `aria-role="button"`，整宽按钮在 wxml 里写
  `style="display:block;width:100%;max-width:none"`——与首页主入口同一种写法。
- **改完 WXSS 要重启开发者工具**：只 `npm run build` 时模拟器仍用上一次编译的样式
  （本次实测按钮宽度 161px → 重启后才是设计值 61px）。

## 待拍板项

1. **「计入当天」的含义**。本稿：打开后剩余天数含今天（目标日为明天 → 「还有 2 天」）；
   今天当天一律显示「就是今天」。备选读法是「目标日当天仍算在期限内」（只影响过期判定）——
   但那会让今天出现两种状态，因此没有采用。要改的是文案与 `+1` 这一处规则。
2. **首页入口的形态**。本稿在「学生部门 / 校园资讯」下方加一条横带，显示最近一条目标日与剩余天数；
   没有目标日时显示「去添加」。备选是塞进 `entry-pair` 变成 2×2 四格（会改动已定稿的首页版式）。
3. **已过期条目是否自动隐藏**。本稿不隐藏，留在「已过期」分组并标出过期天数；
   备选是只保留最近 30 天、更早的折叠起来。
4. **删除确认用系统弹窗**（`wx.showModal`）而不是图 04 画的自绘弹层：与课表删除保持一致，
   少一处自绘交互。图 04 保留的是文案与信息层级。
