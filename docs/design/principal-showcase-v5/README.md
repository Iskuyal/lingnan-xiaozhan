# 校长审核材料：功能、过程与结果

状态：2026-10-04展示材料版式试制方案，供负责人审阅。仅更新PPT、PDF与代码演示，不修改真实小程序界面；原生小程序的设计审批、实现与验收另计。

## 简报与完成约定

校长与审核老师通过介绍材料理解项目用途，看清学生操作过程，并判断操作产生了什么结果。平台为16:9投影、离线MP4、可编辑PPT，以及支持暂停回放的浏览器演示。保持岭南红、校徽金与现有产品任务名称；不展示真实学生数据或未获批能力。

v4基线的问题：每章以大标题和手机为主，用途与步骤已有表达，但结果停留时间不足，截图导入、校历与考试、手工维护和升学出处未完整演示；PPT截图较小，没有统一给出输入、操作、输出。v4源文件与代表性画面保留在本地`artifacts/product-demo-v5/baseline/`。

本轮采用普通改版完成约定：授权范围完整、重要交互和可读性缺陷解决、主要结果可见。不设通用9分门槛。安排1名全新上下文视觉评审，最多3轮；沿用继承模型。固定提示为ui-product-design的`references/critic-prompt.md`原文。静态评审不能替代完整动态、真实用户与真机验收。

## 方向比较与视觉契约

| 方向 | 构图与信息顺序 | 判断 |
| --- | --- | --- |
| 校园任务画册 | 保留产品手机界面，沿“功能介绍、使用过程、最终结果”显示任务阶段；结束时放大成果 | 采用。与校长审核的问题直接对应，产品与结果都可看清 |
| 多设备电影空间 | 以旋转手机、长镜头和抽象图形表现技术 | 暂不采用。动画成本更高，也容易削弱输入、步骤与成果的判断 |

品牌已确定，沿既有岭南红与校徽金深化，不以随机种子替换品牌决策。标题使用Microsoft YaHei Semibold及中文系统回退；正文使用Microsoft YaHei。视频主标题约58px，操作说明24px；PPT正文约20pt。颜色延续真实产品：动作红`#c41c23`、品牌深红`#8c1614`、金`#c69a28`、纸底`#fdf7f5`、正文`#2b2422`、次要正文`#6b5d57`。金用于装饰与阶段线，普通正文使用深色。

画面上方用三阶段轨道解释当前位置；操作阶段以按钮、输入与状态变化为焦点；结果阶段保留产品界面，并显示具体输出，如“6门课程已保存”“新增课程出现在周四第9–10节”“目标日剩余7天”。PPT保留可编辑标题、步骤和结果文字，以代码演示画面解释例子。

窄屏演示将讲述区与手机重排为纵向，保持手机可操作；不单纯把1600px舞台缩成不可读的小图。暂停、拖动、键盘关闭与减少动态保留状态含义。产品内的业务字段不改变；仅演示数据与材料布局更新。

## 任务与结果覆盖

| 功能 | 使用过程 | 最终可见结果 | 必要边界 |
| --- | --- | --- | --- |
| 首页 | 打开入口、选择功能 | 找到校园信息与个人安排入口 | 学校题材参赛作品 |
| Excel导入 | 聊天选择文件、解析、修正、确认 | 6门演示课程进入周课表 | 确认前不保存，取消不覆盖 |
| 截图识别 | 选图、识别、校对、确认 | 校对后的课程进入课表 | 固定模拟识别，不宣称准确率 |
| 周课表与手工维护 | 切周、看详情、手工新增和修正 | 新课程、修改后的地点可见 | 不接触教务账号 |
| AI查课 | 输入问题、查看基于课表的回答 | 周次、课程、节次和地点 | 固定示例响应 |
| AI增改 | 指令、提案、用户确认 | 新课程显示在指定节次 | 取消不变更；失败可用手工入口 |
| 部门资料与问答 | 列表、详情、围绕资料追问 | 职责、下设部门、来源或缺失说明 | 学生组织，不是行政审批 |
| 校园资讯 | 列表、详情、阅读、查看来源 | 文章摘要与原文来源 | 历史公开资料，不是今日更新 |
| 目标日 | 填名称与日期、保存 | 个人目标与剩余天数 | 演示基准日2026-10-04；本机数据 |
| 校历与考试 | 选择已登记事项、核对官方资料 | 已核准日期或官方入口 | 报名截止以考点公告为准 |
| 体测估算 | 七项合成输入、计算、看明细 | 参考总分81与分项分数 | 不代表学校正式成绩 |
| 升学资料查询 | 澄清类别年份地区、查资料 | 原文摘录与出处、降级说明 | 2026历史资料样例；模型效果待验收 |
