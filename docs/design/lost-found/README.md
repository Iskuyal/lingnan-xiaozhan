# 设计说明：失物招领（lost-found）

状态：**待评审**。本目录为 `docs/tasks/lost-found-framework.md` LF-2 阶段的评审件；
页面代码在评审定稿前不落地（当前阶段产物仅本目录与领域文档 `docs/domain/lost-found.md`）。

## 为什么改

新增业务域：失物招领双向匹配。界面必须同时服务三件事——**信息可检索**（列表/筛选）、
**防冒领**（私密特征不外显、核验走结构化表单）、**可信度诚实表达**（相符点/冲突点/不确定性、
档位置信度，禁用「AI 已确认」文案）。

## 版式规则（实现依据）

- 页头：品牌红渐变（`--brand` → `--brand-deep`），白字标题 + 灰色小字说明（`--nav-sub`）。
- 丢失/拾获切换：圆角分段控件（seg），选中态品牌红底白字。
- 卡片：`--glass-strong` 底 + `--glass-line` 描边，圆角 16px（`--r-card` 减一档，卡片在玻璃面上）。
- 徽标：丢失=红（`rgba(196,28,35,0.12)` 底/`--brand` 字）、拾获=金（`rgba(198,154,40,0.18)` 底/`--gold-deep` 字）、
  状态=灰、警示=琥珀（`--warn` 系）。**失败与警告一律琥珀，不占品牌红**（CONTEXT.md 已定规则）。
- 解释三段色：相符=绿 `#2e6b3e`、冲突=`--brand`、不确定=`--text-3`。
- 表单错误：琥珀描边 + 琥珀错误文案，不用红框（同上规则）。

## 待拍板项

1. 首屏默认页签是「拾获」还是「丢失」（本设计默认拾获）。
2. 类别枚举（证件/电子设备/校园卡/钥匙/其他 是否够用）。
3. 时间粒度（本设计用「上午/中午/下午/傍晚/晚上」时段 + 日期）。
4. 地点粒度（本设计用「校区 · 区域」，区域名清单待定）。
5. 首页入口层级（首页入口卡片 vs 独立 tab）——首版建议首页入口卡片，不新增 tab。
