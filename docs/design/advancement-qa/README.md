# 升学与实习问答（本地演示形态）

状态：**待评审**（2026-09-29）。两张静态稿已渲染（`png/`），实现已落到
`miniprogram/pages/advancement/`；待拍板项在最后一节。

对应 [Issue #94](https://github.com/Iskuyal/wx-match/issues/94)。**这一版按 #93 的 go/no-go 做的是
「本地演示」形态：不接模型**——[PoC 结论](../../evidence/advancement-poc/README.md)是条件性 go，
内容安全额度用尽让「模型照着检索结果回答」这一层没有验，因此界面只展示**检索到的官方原文段落 + 出处**，
澄清与拒答是固定话术。

## 为什么这样画

这一屏的风险在「看起来像智能问答」。所以：

- 标题区固定写「只答官方原文里写过的事 · 语料 4 份 / 25 个段落 · 核查 2026-09-29」；
- 开头一句明确「**没有接模型**：回答是原文摘录」；
- 回答卡片与**出处卡片成对出现**：出处卡片给标题、文号、发布主体、发布日期、适用地区、核查日、
  逐字引文与「复制原文链接」；回答本身只是引文的原样拼接（服务层保证 `answer === 引文`）；
- 澄清与拒答用琥珀块（与品牌红分开），澄清给可点选项，拒答给官方入口；
- 语料不含的内容（岗位、薪资、分数线）一律拒答，不给「相关段落」硬答。

## 版式规则（390px 画布，1px = 1.923rpx）

- 输入行：输入框与「提问」按钮同高 48px，按钮宽 76px、品牌红底白字；
- 示例问题：胶囊 34px 高、11px 字，最多两行；
- 提问气泡：品牌深红底白字 14px；
- 回答卡：左边框 3px 品牌红，回答文本 14px/600/行高 1.8；
- 出处卡：`--paper-shade` 底，引文左侧 2px 金线，元信息 10px，复制键 10px/700；
- 澄清 / 拒答：琥珀边框 + 左侧 4px 琥珀块，正文 13.5px。
