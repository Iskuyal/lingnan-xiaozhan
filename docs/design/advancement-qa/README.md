## 为什么这样画

这一屏的风险从「检索不到」变成了「模型补出原文里没有的日期、条件与数字」。所以：

- 顶部不再写「没有接模型」，改成三句话讲清边界：**AI 依据原文解释**、**核不到出处的回答不会显示**、
  澄清与拒答仍由规则触发；
- 模型解释里的每个事实句带 `[S1]` 形式的出处编号，出处卡片的标题上带同样的编号（`04-qa-model.png`）——
  编号与卡片一一对应，学生可以逐句核对；
- **等待态**写清「在等什么」与「只能用什么资料」，并给「取消，直接看原文」的出口（`05-qa-loading.png`）；
- **降级态**不是错误页：主文本是这次检索到的原文摘录，说明里点出降级原因与核对点，并给「重试 AI 解释」
  （`06-qa-fallback.png`）；
- **模型说无法核实**用琥珀块与「无法核实」同一套样式，并把检索到的原文一并列出，由学生自己判断
  （`07-qa-refused.png`）；
- 首版的 01–03（原文摘录 + 出处卡片 / 澄清与拒答 / 范围确认）保持不变：澄清、拒答、年份与地区确认
  这三条路径本轮没有改。

## 版式规则（390px 画布，1px = 1.923rpx）

沿用首版：输入行 48px 高、按钮 76px、示例胶囊 34px、提问气泡品牌深红、回答卡左边框 3px 品牌红、
出处卡 `--paper-shade` 底 + 金线引文。新增：

- 等待态：虚线边框 1px、`--brand-deep` 13.5px 标题、11px 说明、3px 进度条（金色实心 58%）、
  取消键 37px 高 12px 字；
- 出处编号徽标：`--gold` 11px，放在标题左侧 4px 处；
- 降级后的重试键：44px 高、14px 左右内边距、13px/700 字；
- 模型拒答块：与语料不含数据的拒答同一套琥珀（`--warn-soft` 底 + `#c68a32` 左边框 3px）。
