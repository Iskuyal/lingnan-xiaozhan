# 设计说明：部门动态 RAG 来源条

状态：**待评审**（实现已先行合入 feat/department-activity-rag；按约定本应设计图定稿后再改代码，此处补交评审件，待负责人拍板后改「定稿」，如与实现有出入以评审结论为准回改代码）。

## 为什么改

部门问答（Ticket 07）原本把活动动态标题全量塞进每次提问的提示词。本次改成云函数内 bigram 检索注入（ADR-0002）：动态类问题命中时，回答下方出现「参考来源 · 部门动态」来源条；基础问题（联系方式、校区、下设部门）不触发检索、无来源条。

## 做什么 / 不做什么

- 做：来源条 = 分节头「参考来源 · 部门动态」+ 命中条目卡片（标题 + 发布日期 + 「点击复制原文链接」），每条点击整条复制官网原文链接（toast 确认）。
- 做：无命中时不渲染来源条（`wx:if`），气泡其余部分不变。
- 不做：不在来源条上做打开原文内嵌页/WebView——与资讯详情「复制原文链接」交互保持一致，避免引入新组件。

## 版式规则（实现依据）

- 分节线：1rpx 实线 `--gold-deep`；分节头字号 21rpx、`--text-3`。
- 条目卡片：背景 `--glass`、1rpx `--gold-deep` 描边、圆角 `--r-control`、内边距 10rpx 14rpx、条目间距 8rpx。
- 条目标题 24rpx / 1.5 行高；元信息（日期 + 点击复制原文链接）21rpx、`--text-3`。
- 来源条整体与气泡内容间距 12rpx，上沿 1rpx 金色细分隔线（`--gold-deep`，透明度感由 1rpx 细线承载，不用低透明 rgba，色值全部走令牌）。
