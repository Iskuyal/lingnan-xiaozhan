## 3. 改进与重要残留问题

1. **P2，56／57 材料长文中段，尤其 320px 的 F5 阅读位置。** 观察事实：全页稿把返回按钮放在顶部和全部条目之后；`material-320-F5.png` 中可见 F5–F8 内容，看不到返回作答／重答草稿动作。影响：学生读完相关依据后需要回滚多屏或继续到底部，容易丢失当前阅读位置。具体修改：在材料阅读容器提供持续可见的“返回当前作答／返回重答草稿”，并为正文留出足够空间避免遮挡；也可在当前引用条目后设置就地返回动作。如何复查：分别在 320px 的 F4、F5 中段视口检查返回动作可见、正文不被遮挡；交互实现后再核查回到原轮、草稿内容及焦点／滚动恢复。

本次查看范围内未发现周次丢失、把第 7 周选入、F4／F5 入口缺失、材料正文缺项或重答页面完全没有返回出口等高影响可见缺陷。以上是静态设计判断，不等同于业务验收通过。
