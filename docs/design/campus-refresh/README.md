# 岭南校园服务 · 全模块界面改版

状态：定稿（2026-09-25）。负责人已确认重绘范围覆盖着陆页、资讯、部门、课表及各自子页面；20 张静态稿已渲染，小程序 WXML/WXSS 也已同步更新。

## 设计意图

把当前以磨砂卡片为主的页面改成一组辨识清楚的校园服务场景。首页承担入口导航；资讯像一张可读的校园公告；部门页像一册组织名录；课表保留紧凑网格；导入、编辑、管理和设置使用明确分组的工具台。

本目录取代本项目主路径页面的旧视觉规范；docs/design/timetable 保留课表功能规则与历史交互示例，课程几何（包括 84rpx 节次行高）仍沿用现有实现。

随机灵感只转成抽象构图：用 12×8 像素画布、大小块交替、非均匀间距来构成一座校园门楼。稿件和成品界面均不呈现原始字符串、字符序列或数字序列。

## 视觉系统

- 核心色：岭南红 #c41c23、深红 #8c1614、校徽金 #c69a28、纸白 #fdf7f5、墨色 #2b2422。次级文字 #746760 在纸白/纸色上分别约为 5.14:1 和 4.80:1。警告只用琥珀 #9a5b1e。
- 字体：系统黑体承载导航、正文、表单和课表；系统宋体只用于首页主标题与资讯重点标题。没有外部字体依赖。
- 画布：390px 宽；页面横向留白 18px；主要正文行长控制在约 34 个汉字内。课表保留已验证的 84rpx 节次行高；空课日保留约 29px 窄列并只显示单字星期，日期数字留给周范围与课程详情，保证窄列仍可辨认。
- 形状：方角、6–12px 小圆角优先；不使用全局磨砂、重复的卡片投影或大面积渐变。
- 标识：像素门楼只用于首页主视觉。其他页面以新闻标题、组织名单、课表网格和表单自身形成场景。
- 状态：空数据、错误和待核对用中性纸面或琥珀提示；品牌红只表示入口和主要动作，不表示失败。
