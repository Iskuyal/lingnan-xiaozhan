## 参赛约束

- 每队 1–3 名来自同一学校的学生；指导老师不超过 2 名。
- 研究生只能报研究生组；985/211 本科生报 A 组或研究生组；其他普通本科生报 B 组或更高组；高职高专学生报 C 组或更高组。
- 项目需结合微信生态、AI 与真实业务场景；可围绕校园、数字生活、产业、文旅、公共服务选题。
- 技术表格属于建议能力，不要求堆叠所有能力；根据核心流程选择实现。

## 提交约束

七项核心内容缺一不可：项目说明、小程序与 AI 能力说明、创新点、技术实现、成果展示、历史说明、落地规划。
附件仅接受 ZIP，大小建议不超过 300MB，命名为 `第九届传智杯-AI小程序赛道-作品名称.zip`。
建议包含源代码、演示视频、作品说明、必要的体验说明与测试账号或体验二维码截图。
体验版配置或正式上线及相关凭证属于加分材料；是否具备条件需在项目规划中确认。
往届作品迭代需注明优化部分，无过往成果时填写“无”。

材料逐项验收见 [提交模板](submission.md)。
