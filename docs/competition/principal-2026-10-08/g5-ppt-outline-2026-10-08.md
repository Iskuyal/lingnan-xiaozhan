## P02 · 学生要讲清楚自己的项目，缺的是"依据在哪"

**预计停留：35 秒**

- 真实学生困境（**本条是原创设计情景，不是真实学生记录**）：被问"这个功能怎么保证不重复提交"，回答"应该不会重复吧"——**说不清依据、边界和下一步**。
- 我们要练的不是口才，是**三件事**：依据在哪、哪些还没验证、下一步补什么。
- 明确划界：**不给学生打分，不评诚信、不做职业能力等级**；反馈只做"与材料对不对得上"。
- 结论句：这类练习的价值在**可回核**，而不是"AI 说得像模像样"。

## P08 · 成本、额度与时间预算（如实口径）

**预计停留：30 秒**

- **时延**：模拟器 **16.9–33.2 秒**（n=10，中位 22.9）、真机 **≲45 秒/轮**（重答轮 **≤48 秒**）；页面文案已由"12–23 秒"改为 **20–45 秒**（设计图 + 代码同步）。**"12–23 秒"这个口径已作废**。出处：[设计契约 5.1](../../design/project-defense/README.md)、[g5-inputs 第一节](../../evidence/project-defense-g4/g5-inputs-2026-10-02.md)、[真机记录](../../evidence/project-defense-g4/real-device-2026-10-02.md)。
- **为什么变慢**：换第三方审核后每次业务请求多 2–4 次审核模型调用（单次 **1.7–2.9 秒**）⇒ 约 **+4～12 秒**。**这不是功能变慢，是审核链路变了。**
- **成本实测**：当月 **278 次 / 266,612 token / 0.066670 元**（[usage-after-realdevice-2026-10-02.json](../../evidence/project-defense-g4/usage-after-realdevice-2026-10-02.json)，读数时间 2026-10-02T05:18Z；[真机记录第 3 节](../../evidence/project-defense-g4/real-device-2026-10-02.md) 记同一个值）；上限 50 元、告警线 40 元 ⇒ **未告警未超限**；**剩余额度读不到，不写剩余值**。
  > **脚注（口径差异，正文不引用）**：[G4 → G5 输入清单](../../evidence/project-defense-g4/g5-inputs-2026-10-02.md) 另记一条更晚的**散文读数**「**282 次 / 275,813 token / 0.068970 元**」，仓库内**无对应 JSON 入库**；[usage-2026-10-02-final.json](../../evidence/project-defense-g4/usage-2026-10-02-final.json) 是更早的一次读数（**255 次 / 234,750 token / 0.058700 元**）。两者都**不是**正文口径。
- **两个额度上限**：微信内容安全 **100 次/天**（全功能共用，约 5–6 次完整会话打满）；个人日上限 `AI_USER_DAILY_LIMIT` = **30**（约 6 次会话打满，**被拒绝的请求也计数**）。
- **客户端超时兜底**：本轮 PR 加入 75 秒兜底，高于实测上界；超时进入 `model_unavailable` 并保留草稿和重试入口。设计契约已同步为 75 秒，30 秒未实现的描述仅属历史。本地回归已通过，真机超时验收仍未补齐。

**证据文件**：[G4 → G5 输入清单](../../evidence/project-defense-g4/g5-inputs-2026-10-02.md)（时延、额度；**该页的成本散文读数未入库，正文不采用**）；[设计契约 5.1](../../design/project-defense/README.md)；[第三方审核切换记录](../../evidence/project-defense-g4/safety-provider-switch-2026-10-02.md)；[当月用量（真机后读数）](../../evidence/project-defense-g4/usage-after-realdevice-2026-10-02.json)

- 「内容安全检测的额度已用尽…45009」= **微信侧**当日配额；「今日调用次数超过 30 次」= **我们的个人日计数**（`AI_USER_DAILY_LIMIT=30`）。两者 `failureClass` 都是 `quota_exhausted`，**原因不同，别答错**。⚠️ 但这两句都是**服务端原始返回**：`defenseFailureCopy` 对 `quota_exhausted` 返回**固定文案**「**额度或当日检测配额已用尽**」（不采用服务端 `message`），页面只渲染该标题与正文，客户端 `AiCallResult` **没有 `detail` 字段** ⇒ **页面上两个上限文案相同、现场不可区分**。现场**只按「额度用尽」如实说，不要猜是哪一侧**；要区分只能用 `scripts/probe-ai-raw-response.cjs` 的原始返回或云函数日志。
- 失败四分类（`model_unavailable` / `content_rejected` / `quota_exhausted` / `invalid_request`）各自独立文案，页面按类映射。
- 「这次反馈没有通过引用核对」= 服务端 `verifyDefenseAnswer` 闸门拦下，**不显示半截内容**。

## 本结构不得出现的表述

以下沿用仓库口径（见 [G4 主清单"不得据此声称"](../../evidence/project-defense-g4/README.md) 与 [g5-inputs 第五节](../../evidence/project-defense-g4/g5-inputs-2026-10-02.md)）：

- 不得说新功能**已上线 / 已被学生使用**；不得说**教师已认可或已评价**。
- 不得说**真实学习效果达标**（本功能从不产出分数/等级，真实学生样本 0）。
- 不得说**引用核对已 100%**（那是维护者自编 8 例的结论，不是在线保证）。
- 不得说**两位评审已复核**（只有 1 个人 + 1 个 AI）。
- 不得说**真机是负责人手点的**（实际是 `adb` 自动化驱动）。
- 不得说**基础库版本已记录**（未读到，标"未核实"）；不得说**返回手势已验证**（未取得结论）。
- 不得把**第三方审核下的时延/成本**说成默认配置的表现；不得说 G4 那批结果代表默认配置。
- 不得说**除已记录缺口外其它缺口已修复**。
- 不得写**授权结果**，不得出现"学校已授权"字样。
