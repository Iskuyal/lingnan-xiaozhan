## 1. 安装与构建

需要 Node.js ≥22、npm、微信开发者工具以及对应团队的 AppID/云环境访问权限。此前完整仓库767项测试通过，源码审查子包只提供可安装构建的源代码，排除整个tests及含个人信息的真实课表夹具。

在解压的`源代码/`目录运行：

```powershell
npm ci --ignore-scripts
npm run typecheck
npm run build
```

独立解压目录已按以上顺序验证通过。开发者工具导入生成的`dist/`，不是`miniprogram/`。构建不会上传云函数；`dist`是可重建目录，不应手工修改。源码子包不运行`npm test`和`npm run docs:check`，这些检查需要完整仓库的tests与文档。

## 3. 数据与存储

| 数据 | 集合 / 位置 | 权限和验证重点 |
| --- | --- | --- |
| 个人课程与可见批次标记 | `timetable_courses` | 普通客户端数据库访问取最严格的不可读写预设；服务端按调用上下文身份隔离。整份导入先写staged批次，再切换head可见批次 |
| 个人设置 | `timetable_settings` | 同上；客户端不能替自己指定其他人的owner |
| AI调用记录、月度汇总 | `ai_usage_records`、`ai_usage_monthly` | 由服务端读写；维护者查询受白名单限制，不对普通客户端开放原始记录 |
| 官网资讯 | `news_articles` | 前端仅读取公开文章；写入由服务端同步，不开放客户端写入 |
| 同步状态 | `sync_state` | 服务端维护，普通客户端不可读写；定时实际执行需另查日志 |
| Excel/截图临时上传 | 云存储本人路径 | 路径由服务端准备；解析/识别后尽力清理，是否残留按实际结果记录 |

课表数据、截图和openid不随本包提供。真实业务验证使用可丢弃账号与课程，先备份现有数据；本轮没有替换真实课表。完整账号删除、第三方留存和处理地区仍未形成已验证承诺。

## 4. AI配置字段

下表只列配置名称与作用，不提供可直接用于生产的凭据或预设套餐。定义见[config.ts](../../cloudfunctions/ai/config.ts)。

| 配置组 | 字段 | 处理方式 |
| --- | --- | --- |
| 文本与图片模型 | `AI_PROVIDER`、`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`、`AI_VISION_MODEL` | 按实际服务填写；OpenAI兼容分支需要base URL、key和model。视觉模型未单独配置时复用文本模型，但服务是否支持多模态须实测 |
| Anthropic协议分支 | `AI_ANTHROPIC_BASE_URL`、`AI_ANTHROPIC_API_KEY`、`AI_ANTHROPIC_VERSION` | 仅在选择相应协议时核对，不混用两种协议的必填项 |
| 输出与时间预算 | `AI_MAX_TOKENS`、`AI_TIMEOUT_MS`、`AI_TOTAL_DEADLINE_MS`、`AI_EXTRA_BODY_JSON` | 代码会钳制范围；当前实际值需读回。客户端75秒兜底不是正常响应目标，也不代替服务端预算 |
| 内容安全 | `AI_SAFETY_PROVIDER`、`AI_SAFETY_FAIL_MODE`、`AI_MODERATE_OUTPUT`及相应审核接口字段 | 默认代码走微信审核，旧实测曾为第三方openai；现场重新确认。缺少配额或配置时保留失败反馈，不为演示关闭审核 |
| 成本 | `AI_PRICE_INPUT_PER_MILLION`、`AI_PRICE_OUTPUT_PER_MILLION`、`AI_MONTHLY_CAP_YUAN`、`AI_CAP_WARN_RATIO` | 填真实服务价格；服务端估算不等于第三方结算，旧4条空响应须先核账 |
| 身份与限流 | `AI_ADMIN_OPENIDS`、`AI_USER_MINUTE_LIMIT`、`AI_USER_DAILY_LIMIT` | 白名单、限流值在服务端配置，不把原始身份或密钥写入提交材料；当前日余量不能沿用历史数字 |

## 6. 体验路径与失败排查

| 现象 | 先核对 | 保留的边界 |
| --- | --- | --- |
| Excel选不到 | 文件是否已发送到微信聊天，导入页是否使用聊天文件选择 | 小程序不能直接浏览电脑或手机任意文件目录 |
| 首页可开但课表/资讯失败 | AppID与云环境关联、前端env、函数和数据库权限 | 本地构建成功不代表云资源可用 |
| AI配置不完整或审核失败 | 目标函数环境变量、审核提供方、配额和用量记录 | 不连续重试，不切换为关闭审核，不把原文降级记作模型成功 |
| 自动化端口无响应 | 是否为当前dist、CLI auto是否已开启；本机初轮重启后恢复的记录另存 | 重启后10项离线通过，不外推真实上传/保存与模型效果 |
| 课程保存状态不确定 | 刷新本人课表，检查可见批次与服务端结果 | 不盲目再次整份替换或删除可能已经生效的课程 |

本轮390px原生模拟器使用内存夹具，已完成10项交互检查与30张截图；真实上传、保存、AI效果及真机仍需独立证据。当前未提供通用测试账号、长期二维码或评委访问凭据。测试账号由负责人在受控交接中提供，不写进公开仓库。
