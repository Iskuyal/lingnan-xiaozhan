## 片中实际完成的流程

首页 → 周课表切换 → 虚构 Excel 实际上传和云端解析出 5 门课程 → 修正草稿地点 → 放弃导入并确认原课表不变 → 手工新增临时演示课程并保存 → 在课表和详情里查看 → 查阅部门资料 → 阅读云端资讯正文与来源 → 返回首页。

文件选择器由自动化传入虚构课表，配音已明确说明；上传、云函数解析、课程读写与资讯读取实际运行，没有替换业务返回。课程与教师样例为虚构输入；录制中不展示真实教师详情。录制后删除唯一新增的演示课程，原有 **51 门课程逐项一致**，校验摘要见验证记录。
