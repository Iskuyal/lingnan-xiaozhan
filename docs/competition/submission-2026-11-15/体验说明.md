本说明适用于2026年11月15日r4交付。仓库为https://github.com/Iskuyal/lingnan-xiaozhan，代码已合入main。作品为学生参赛原型，不代表学校正式运营服务。

作品说明覆盖a至g七项。新版演示展示最新原生界面，使用虚构数据和固定AI测试响应；历史真实AI视频对应2026年10月30日版本，两者分开标注。源码子包、评委虚构课表、截图和清单在ZIP内。

## 安装与构建

安装Node.js 22或以上，在源码子包根目录执行：

```powershell
npm ci --ignore-scripts
npm run typecheck
npm run build
```

在微信开发者工具导入生成的dist目录。不要把手工内容放进dist，也不要修改生成物来替代源码变更。

子包排除含个人信息的课表夹具及完整tests，验证范围为干净解压后的安装、类型检查和构建。完整1025项回归在仓库执行，需要完整代码与相应资料权限；不能宣称本子包复现了全部测试或文档检查。

## 建议体验路径

先浏览今天、学习和校园，再进入课表。测试导入时使用空白或专用账号，将“岭南小栈-评委测试课表.xlsx”发到微信聊天，再在小程序从聊天选择。附件为13条虚构记录，没有真实学生数据。

导入后核对课程名、星期、节次、周次和地点，可逐条修正或放弃。本次确认保存会整份替换账号全部已有课程，包括手工新增和修改，请勿在存有重要课表的账号上随意确认。

保存后查看周和日安排、完整12节、周末及晚课。未填作息时只显示节次，不推断钟点。手工编辑、删除均需核对其影响。

在助手中查课，或粘贴限定周次通知，核对原文、前后差异和具体周次。确认前不写课；部分成功只重试失败项。撤销有有效窗口，并受后续课程修改保护。

在学习页创建目标，输入情况或使用基础规则。核对AI原话依据后生成规则预览，再保存到本机。计划在课表中单列，不计课程数。目标变更、删除、过期或有新课程冲突时先看提示，不假设已自动重排。

校园资料保留来源与日期。练习等待取消和材料查阅应保留原答；主动复制记录不补写未返回反馈。体测为国家标准参考，缺项不出学年总分，不作为学校成绩。

## 失败与数据处理

读不到课表时应显示读取失败，不能当作今日无课。模型不可用时保留草稿与重试入口；内容拒绝、额度不足和服务错误分别提示。资料缺失或年份、范围不符时，以缺失说明或原文回退为准。

个人课程由服务端按微信身份读写；临时图片和第三方模型处理按实际配置及数据使用说明核对。完整接收方、保留期限、删除途径仍需负责人按试点情况确认。计划只存本机，练习主要在页面内存，退出清空前会提示。

编译异常时先确认导入的是本次dist，再按开发手册清理缓存。模拟器、固定响应和本机测试不证明真机、真实模型质量或正式部署。
