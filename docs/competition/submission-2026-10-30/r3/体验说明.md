## 本地安装与构建

需要 Node.js ≥22、npm、微信开发者工具，以及合法的AppID／云环境权限。在“源代码”目录执行：

```powershell
npm ci --ignore-scripts
npm run typecheck
npm run build
```

微信开发者工具导入生成的 `dist/`。`miniprogram/` 与 `cloudfunctions/` 是源码，`dist/` 是生成物。安装或构建不代表云函数已经部署；本轮独立解压验证的实际结果见包内验证报告。

源码交付子集不附含真实教师与班级信息的测试夹具，也不附完整tests目录，不在该子包承诺 `npm test` 或仓库级 `docs:check` 可复现。完整仓库的历史测试与本包安装构建检查分开记录。

## AppID、云资源与配置

| 项目 | 配置入口与动作 |
| --- | --- |
| 小程序工程 | 核对 `project.config.json` 的AppID、基础库及团队权限；仅有源文件不提供账号授权 |
| 前端云环境 | `miniprogram/app.ts` 显式指定环境；换环境时同步核对，环境标识不是密钥 |
| 云函数 | 在有权使用的环境部署 `ai`、`timetable`、`newsSync`，函数依赖按各自锁文件安装 |
| 数据库 | 按源码建立课程、设置、AI用量／月汇总、资讯与同步状态集合；服务端按上下文身份隔离 |
| 临时上传 | 配置本人可读写的存储权限；解析／识别后按业务流程清理，不将草稿误当正式课程 |
| 模型与审核 | 在服务端配置提供方、接口地址、模型及密钥；不把密钥写入前端或参赛材料 |
| 限流与记账 | 核对当日／当月用量、真实单价与月度上限；历史读数不当作实时余额 |

AI主要字段包括 `AI_PROVIDER`、`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`、`AI_VISION_MODEL`、`AI_SAFETY_PROVIDER`、`AI_MODERATE_OUTPUT`、`AI_MONTHLY_CAP_YUAN` 及相应超时／限流配置。完整字段以冻结源码 `cloudfunctions/ai/config.ts` 为准。现有配置和第三方服务可能发生超时，不为演示关闭审核或编造成功返回。

`newsSync` 的定时配置文件只证明计划配置，实际触发状态与运行日志另计；不要为补截图开放普通客户端写入或自动全量抓取。

## 建议体验路径

1. 首页进入学生部门，查看职责及来源；进入校园资讯，阅读标题、日期与正文。
2. 打开“我的课表”，用个人有权使用的Excel或演示用虚构课表导入；先核对草稿再决定保存／放弃。
3. 查看周课表，手工新增一门可删除的临时课程，刷新核对，再自行删除；不要直接替换重要课表。
4. AI实际体验前先确认服务与额度；查询只读，变更须本人确认。成片实际完成5次业务AI请求；具体采样成功不保证后续服务稳定。

## 常见失败与边界

文件应先发送到微信聊天，小程序不能任意浏览手机文件目录。云端读取失败时核对AppID、环境关联、函数与数据库权限。模型或审核失败时保留页面提示，已有课表仍可查看，手工维护入口继续使用；不要反复提交不确定是否已经生效的保存操作。

本包不提供长期有效的体验二维码、公开测试账号、生产凭据或自动部署权限；需要实际云资源的体验应由拥有权限的成员操作。学校上报已按负责人决定关闭，本轮没有代为提交表单、发布视频或上传网盘。
