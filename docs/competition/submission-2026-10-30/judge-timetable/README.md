## 直接导入

1. 将Excel文件发送到微信聊天，例如“文件传输助手”；不要把文件截图后当作Excel文件选择。
2. 打开岭南小栈 → 我的课表 → 导入课表 → 从微信聊天记录选择文件。
3. 选择此文件，等待上传与云端解析；确认页应显示 **13门课程、0门待核对、0门需要补全**。
4. 需要体验保存时，先核对草稿，再点“确认保存”。**确认保存会整份替换当前账号已有课表（含手工课程），请使用空白或专用测试账号。** 只想查看解析效果，可以点“放弃导入”，已有课表不应改变。
5. 返回周课表，用周次选择器切换第1、4、7、9、10、16周；不需要填写或猜测学校真实开学日。

本轮对文件运行了冻结源码的解析器和保存字段校验，没有替评委执行云端保存，也没有写入维护者现有课表。实际微信文件选择、云资源权限和网络可用性按评委环境处理；这份离线验证不冒充真机或云端端到端验收。
