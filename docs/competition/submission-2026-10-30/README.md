## 实际验证与范围

ZIP的命名、CRC、路径过滤、逐文件SHA-256、密钥模式扫描通过；PDF小于表单100MB限制，ZIP小于官方建议300MB。源码子包在独立目录完成安装、类型检查和构建，部门／升学语料与答辩材料均生成；最终包除增加验证报告外，其源码和材料与被验证版本相同。

构建会将 `miniprogram/services/defense/reader-data.ts` 从CRLF重生成为LF，规范化后内容相同；该变化在验证报告中单列。首次严格字节检查的失败与原因保留在本地忽略目录，未改动正式包内的冻结源文件。源码子包未附完整tests及真实课表夹具，不宣称在子包运行全量测试。

当前视频为2分19秒开发者工具原生连续录屏加AI配音，非手机真机；本版没有成功的产品内AI片段。旧失败记录不改写，材料中的历史模型结果也不冒充本轮新评测。
