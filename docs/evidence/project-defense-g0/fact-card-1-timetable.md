## 事实表

| id | 事实 | 状态 |
| --- | --- | --- |
| F1 | 小程序不能浏览手机本地文件，只能通过 `wx.chooseMessageFile` 从**微信聊天记录**选文件；代码含该 API 缺失时的兜底。路径：教务系统下载 → 发到微信 → 在小程序里选 | 已完成 |
| F2 | 文件先上传到本人 openid 下的云存储路径，由云函数 `timetable` 用 `xlsx` 解析成草稿；**解析阶段不写课表记录**，临时文件先删后解析 | 已完成 |
| F3 | 解析对象是**网格矩阵**：前几行元信息，表头「星期一 … 星期日」，其后每行一个大节。单元格形如 `课程名 学分 教师 [周次]周 起-止节 楼-房间-用途 校区 场地编号`；一格可有多门课，已实测单换行与空行两种分隔 | 已完成 |
| F4 | **识别不出的只标记不猜**：用 `warnings`、`weeksRecognized`、`weekText`、`problems` 等字段保留原值与提示，不擅自修复；未识别字段标待核对，由学生在确认页裁决 | 已完成 |
| F5 | 草稿经学生在确认页确认后才写库，**确认前不写**；「放弃导入」不写库、草稿清空（只存内存）。**保存＝整份替换**：会替换本人全部课程，含手工添加的 | 已完成（确认框交互未验证） |
| F6 | 数据按微信身份隔离：读写都在云函数内按调用上下文的 openid 过滤，客户端不直连数据库；上传路径用 openid 哈希前缀，**不接触教务账号** | 代码与桩测试已完成；真实隔离待验证 |
