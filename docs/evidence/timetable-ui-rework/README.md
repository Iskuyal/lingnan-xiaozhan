### `npm run smoke:settings` —— 设置链路通（本轮新增，可重复执行）

```text
设置链路 OK：写入 → 读回一致 → 已恢复旧值（未改变你的真实设置）
明文：{"weekRange":"9/14 – 9/20","week":3,"todayBar":"none｜今天没有安排课程","setupHint":""}
```

它做的事：`getSettings` 读旧值 → 写探针值（开学日 2026-08-31、总周数 20、只填第 5/6 节作息）→
读回断言一致 → 顺手截一张「设置生效后」的课表页 → 恢复旧值 → 再读一次确认恢复。
退出码 0；旧值是「没存过」，恢复成空设置。

## 未覆盖

- **真机**：全部证据来自开发者工具模拟器（`realDevice: false`）。玻璃面的 `backdrop-filter` 在部分安卓机型会被忽略
  （`app.wxss` 已按分层 rgba 做过兜底，但没在真机上确认过观感）。
- **设置页的时间选择器交互**：`picker mode="date" / "time"` 的实际手感与取值没在自动化里驱动过（只验了控件存在）；
  探针是直接调云函数写值的。
- **课程管理的 45 门批量删除**：只验了列表与入口渲染、单条路径的单元测试；大批量删除的耗时与限流没测。
- **编辑页的 `color` 字段落库**：两侧类型与白名单校验有测试，真实云端写入没验。
- **今日速查的四种状态**：`now.ts` 有 10 项单元测试，真实场景只见到「今天没有安排课程」一种
  （当前时间与真实课表不相遇）。
