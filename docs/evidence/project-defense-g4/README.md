### 4. 真实效果首评（与 G1 的区别）

G1 评的是「PoC 能不能产出可判定的反馈」；**G4 评的是已实现功能的端到端输出**，因此规模与要求都要更严：

- [ ] 冻结新样例集（不得复用 G1 那 8 个已用于调参的样例）；留出样例首次结果单列，不得用于调参
- [ ] 逐例按 [rubric.md](../project-defense-g0/rubric.md) 四步判定并保留逐字原始响应：引用核对 → 是否对应回答 → 追问针对性 → **是否把未验证说成已完成**（此项一旦发生即整例不通过）
- [ ] 材料差异一律**提示核对**，不得判学生撒谎、不得道德评价
- [ ] 重答对照：区分「新增可回核依据」与「只把句子写长」
- [ ] 对照实验：同材料同任务的**固定检查表**与**通用 AI 提示**各跑一遍，记录完成步骤、定位依据是否方便、人工判定的有效建议数与完成时间；不故意弱化对照
- [ ] 由两位评审独立复核引用与结论是否对应，分歧单独记录
- [ ] 逐次记录：客户端端到端耗时、服务端耗时、token、费用、内容安全检测次数（**未知不记成 0**）

## 停止与缩减规则（引自阶段方案）

两轮契约/提示词调整仍不达标时，缩为「**单题 → 依据反馈 → 重答**」重测；仍不行则保留探索原型，不以扩语音、图片、RAG 或评分掩盖反馈问题。

## 不得据此声称

- 新功能已上线、已被学生使用、教师已认可或已评价；
- 真实学生学习效果达标、通过率或职业等级有效；
- 引用核对已 100%（那是 G1 对 8 个**维护者自编**样例的结论，不是在线保证）；
- 真机可用或时延达标（本阶段一次都没跑）。
