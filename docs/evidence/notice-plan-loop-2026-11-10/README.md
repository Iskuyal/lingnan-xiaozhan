## 实际交付

- 指定周次的时间与地点一起调整，其他周次保留；同课同范围合并，重复或互斥字段要求核对。服务端原课、拆课、重试/撤销凭据原子提交。
- 同一提案使用稳定编号，提交响应丢失可重试；撤销先核对未被后续修改，再整项恢复。全部周次覆盖原位修改，未识别周次拒绝；每周课要求已保存总周数。
- 规则计划保存后留在已保存视图，重开可离线恢复；目标标识避免同名目标混淆，目标删除/改日期/过期不自动重算或丢失快照。
- 对应日历周课表独立列出计划，不计正式课程数，不随导入替换。课程后改占用时段时提示重排，学期无法对应时明确说明，翻周不重复展示安排。
