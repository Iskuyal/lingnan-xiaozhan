[真实样例报告](live-verified.json)保留原输入、真实返回、解析约束和排程结果。实际审核 `checked=true, passed=true`；报告的 `result.provider` 指审核适配器，不是生成模型厂商。模型返回712个token的已知用量，服务端按配置单价记0.000178元，不代替第三方账单。没有保存新计划或写课程，读取前后51条课程记录逐条比对一致。

首次脚本预检遇到云API尚未初始化，[预检记录](setup-before-request.json)显示模型请求0；先进入正常首页后恢复，只发起了上述1次真实模型请求，没有模型失败重试。

本地已实现：自然情况 → 带原话的约束草稿 → 用户核对 → 规则按课表空档、日期、时长和排除项生成预览 → 保存/离线重开。基础规则作为显式入口，未知或超范围限制不再默认忽略。模型只解释情况，不排具体日期，不直接保存计划。首页布局保留。

**类型检查与918/918测试通过**。新增无效模型字段、原话依据、空输入、三类失败、审核、确认前不生成、重复点击、旧请求回流、目标变动、来源保存和规则上限等用例。原5分钟被提高到15分钟、未理解星期被忽略、可用空档下换排法不变均先复现后修复。
