**必须分开说的两组数字**：

- **独立效果估计（新题首评，实现第一次跑，未做任何针对性调整）：3/7 事实题正确**（守门 6/6）。
  明细：3 题模型解释正确且引用成立；1 题模型回避（语料段落缺小标题，模型如实说"没有直接写明"）；
  1 题模型拒答（语料段落缺主语）；2 题模型答案正确但被**过严的出处校验**拦下（问题里的年份不在段落正文里）。
  **这一组低于 80% 门槛。**
- **修复后的回归（同一批新题 + 历史 20 题，2026-09-30 当天修复后复测）：事实题 18/20 上屏为模型解释且全部正确**
  （新题 7/7、历史题 11/13，另 2 条按设计降级为原文摘录）。

按阶段文档「被用于调参的新题标为回归题，不再冒称独立验证」的口径：**新题现在只能算回归题**，
真正的独立证据只有首评那一组，因此本阶段的 go/no-go 是
**「产品当前状态可用（回归达标）／独立效果估计未达标（首评 43%）」**——要拿到达标的独立估计，
需要用**又一批没见过的题**复测（见「缺口」）。

## 五、本次发现与修复（都带证据）

1. **出处校验过严：问题里的年份被当成"没有出处的数字"**（首评 n01/n06 被拦）。
   段落原文是「网上缴费截止时间为1月23日17:00」，而模型写成「2026年广东普通专升本网上缴费截止时间为1月23日17:00」——
   这个 2026 来自问题与**材料标题**《广东省2026年普通高等学校专升本招生工作规定》。修复：可核对范围
   从"段落正文"扩到"引用卡片上会展示的全部字段"（正文 + 标题 + 文号 + 发布日期 + 适用年份），
   写成 2027 年仍会被拦下（有测试）。
2. **数字等值改写被误判**：模型把「1.5万」写成「15000」原本会判成"没用出处"。修复：数字比较加一层
   **数值等价**（1.5万 = 15000）；数量级写错（15000 → 150000）仍然拦下（有测试）。
3. **语料两段是缺主语/小标题的片段**（首评 n02 回避、n07 拒答的直接原因）：
   `gd-zsb-2026#not-eligible` 缺原文小标题「下列人员不得报考：」、`gd-employment-2026#soe` 缺「发挥国有企业引领作用…」主语。
   2026-09-30 按官方页面（`eea.gd.gov.cn`、`hrss.gd.gov.cn`，各抓取一次）逐字补全，两份材料的 `collectedAt` 改为 09-30，
   其余段落与核查日不变；来源目录与语料 `note` 同步记录。
4. **降级时误挂"本轮回答未经内容安全检测"**（端上真实额度拒绝时暴露）：额度在模型之前被拒时 `safety` 为空，
   页面把"没检测"贴到了官方原文摘录上。修复：这句只在**模型真的出了内容**时提示（有测试）。
5. **评测脚本自身两处**：连跑会撞个人分钟限额（6 次/分）——加 12 秒间隔并对分钟限额等待重试；
   触发限额的那一题按失败记录、可 `--resume` 续跑。

## 七、缺口与未完成项

1. **独立效果估计未达门槛**：新题首评 3/7。要把它抬到 ≥80% 并保持"未见过"的性质，需要一批**新题**
   （不能在本次这 13 道上再调参）；这是本阶段唯一阻挡"模型效果达标"结论的事项。
2. **真实学生提问样本仍为 0**：13 道新题全是维护者设计题，已在 `questions.json` 逐题标注来源。
   不开展公开招募，缺样本就如实登记。
3. **来源冲突场景未覆盖**：4 份语料的 25 段里没有互相冲突的事实，构造不出真实冲突样本；
   检索与守门也没有"冲突检测"能力。
4. **个人日额度是评测的硬约束**：30 次/天，四轮评测已用满；更大的题集需要跨天或申请调额。
   本次的 13 道新题 + 20 道历史题恰好卡在上限内。
5. **真机、时延预算、成本口径**：真机未测；时延预算仍按待办 D1 决定（本次实测 4.0–6.6 秒/次，
   不能写成"≤2 秒达标"）；成本按 0.25 元/百万 token 估算，与中转真实账单的核对仍待负责人。
6. **设计图待拍板**：`docs/design/advancement-qa/` 的 04–07 是本轮新增状态，状态仍是「待负责人拍板」。

## 八、复现方式

```bash
npm run build
npm run eval:advancement -- --plan                 # 只看本地守门与检索，不花额度
npm run eval:advancement -- --set=new              # 新题（13 道，7 次模型调用）
npm run eval:advancement -- --set=legacy           # 历史 20 题（13 次模型调用）
npm run verify:advancement                         # 模拟器端上检查（需先 cli auto 打开自动化端口）
```

前置：`ai` 已部署、当日内容安全配额与个人日额度有余量（见 [云开发手册](../../development/cloud/README.md)）。
评测脚本按 `${集合}:${题号}` 落盘，`--resume` 可续跑；分钟限额会自动等待重试，日额度用尽则停止并保留已完成部分。
