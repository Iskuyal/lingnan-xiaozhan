### 本轮修掉的两处缺陷（都在入库件里）

1. **`ai` 云函数配置事故（零消耗，被只读闸门拦下）**：`AI_EXTRA_BODY_JSON` 曾一度不是合法 JSON，`usage` 动作 2ms 返回 `internal` +「AI_EXTRA_BODY_JSON 不是合法 JSON」——即**整个 `ai` 函数 fail-closed**。按纪律停在真实调用之前、**未发任何 chat 请求**，等负责人改回合法值、只读动作 `ok=true` 后才继续。副产品：这证明**环境变量改动无需重新部署代码即可生效**，此前的「没改 vs 改了没生效」歧义消除。
2. **R5 空回复回灌缺陷（客户端可修）**：R5 的 assistant 消息在**装配阶段**就被固化为空文本（`responsePreview` 初始为空串，之后不再回填），而服务端要求每条消息都有非空 `text` ⇒ R5 只要执行就**必然**被 `invalid_request` 拒绝（两轮实测一致）。修法：新增运行时守卫 `sanitizeEventMessages`，只改**发送时**的消息、不动装配阶段，因此 `--plan` 指纹不变；并补了负例测试。

### 不能过度解读的地方（必须照实说）

1. 本轮**仍未**解决「思考开关是否真的生效」：即便四节写完了，多数响应仍是「大量思考 + 正文」，`completionTokens` 常在 1,700–4,100 之间。`HS-1` 与 `R4` 的空内容就是思考把上限吃满的表现。**提高上限只是把窗口撑大，不是消除不确定性。**

3. `HS-1` 的首次结果**永远是失败**：按纪律不得重跑充当初次结果，也不得把它排除在留出样例之外。
4. `AX-6` 的端上行为（保留原回答、不显示旧结果）**不可验证**——G1 没有页面，不得记成通过。
5. 判定由维护者按 `rubric.md` 人工完成，**不是教师评价**；自编样例只检验机制，**不能**证明学生学习效果、教学有效性或教师接受度。

## 五、阻断缺陷：模型输出预算（本次实测，不是推测）

**症状**（`failureClass=model_unavailable`）：

```text
模型返回内容为空（OpenAI 兼容格式）；choices=1；finish_reason=length；
content=string；reasoning_content=present；error=missing；usage=present
```

**根因**：模型把整个输出预算花在 `reasoning_content`（思考）上，可见的 `content` 为空。

**实测证据（3 条，互相印证）：**

| 观测 | 结果 |
| --- | --- |
| ② 会话批次 5 次 | `ok` 1 / 空内容 3 / `invalid_request` 1 |
| `R2`（唯一成功） | `completionTokens=1025`——**正好顶到默认上限 1024**，正文 529 字后被截断，但服务端按 `ok=true` 返回 |
| 诊断探针（开发样例 `CS1-1`，`maxTokens=2048`） | **仍是** `finish_reason=length`、`content` 为空，`serverElapsedMs=12620` ⇒ **调大输出上限无效，模型只是思考得更久** |

**配置事实（从本地构建源码读出）：**

- `cloudfunctions/ai/config.ts:152`：`AI_MAX_TOKENS` 默认 **1024**（钳 1..8192）。
- `cloudfunctions/ai/config.ts:126-127`：`AI_TOTAL_DEADLINE_MS` 默认 15000、`AI_TIMEOUT_MS` 默认 8000；`index.ts:420-428` 取 `min(请求值, 服务端值, 剩余)`。
- `cloudfunctions/ai/config.ts:154`：`AI_EXTRA_BODY_JSON` 是**唯一**能关思考的入口；`providers.ts:125` 只在服务端把 `extraBody` 合并进请求体，**事件里没有对应字段**。
- `cloudfunctions/ai/index.ts:858-859`：事件可以传 `maxTokens` 与 `timeoutMs`，但 `timeoutMs` 被服务端 `AI_TIMEOUT_MS` 钳住，客户端放不宽。

**为什么不在本阶段修**：客户端能调的只有 `maxTokens`（已实测无效）与 `timeoutMs`（被服务端钳住）；关思考**只能改云函数环境变量**，而本阶段明令「不改任何环境变量」。按续跑提示词，这种情况**记成 G3 的输入并说明理由，不要现在做**。
