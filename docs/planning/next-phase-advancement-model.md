## M1：升学问答模型版

交付目标：学生提问后，系统先确认适用范围，检索有依据的段落，再由真实模型解释并给出可核对的出处；无依据时澄清或拒答，失败时仍可查看现有原文检索结果。

| 工作 | 完成判据 |
| --- | --- |
| 复用 AI 基础服务 | 使用已有 `ai` 云函数的配置、安全、限流、记账与失败分类；密钥保持服务端；本地桩与真实调用分开记录 |
| 来源约束与引用 | 使用版本化来源和服务端约束；引用标识来自可信资料集合；答案中的日期、条件、数字可追溯到所引段落，模型补不出来源时不给官方结论 |
| 澄清与多轮状态 | 当前类别/年份/地区选择有效；新问题清理旧上下文；不同类型不混答，未收录类型拒答；客户端取消/重置后不展示过期请求结果 |
| 页面交互 | 按仓库约定先更新 HTML/PNG、评审定稿；实现等待、重试、失败反馈和原文降级；完成页面行为与模拟器验证，真实设备结果另计 |
| 调用可用性 | 调用前核对实际模型配置、内容安全余额、个人限额与成本配置；记录实际部署版本与回读结果、调用结果、耗时、token 和成本，避免配额不足时反复消耗 |

## M2：真实题集与引用评测

这里的「真实」首先指**真实资料依据与真实模型调用**。维护者设计的业务场景题须标为设计题；确有获许可的真实学生提问才标为真实提问。缺真实学生样本时如实登记，不以合成题、桩输出或短文本冒烟替代真实模型评测，也不开展公开招募。

1. 保留原 20 题和 09-29 原报告。对原题集显式确认适用范围后跑模型，作为历史回归组；原题已用于调参，不能算独立效果估计。
2. 另准备至少 10 道未参与调参的新题，实施前冻结题目、出处、标准答案/应澄清或拒答理由、判定规则。覆盖事实解释、缺失年份/地区、考试类型混淆、过期/冲突来源、无来源和越界问题；覆盖不到的场景单列缺口。
3. 逐题保存问题来源、适用范围、预期依据、检索结果、实际模型答案、引用段落、事实与引用判定、澄清/拒答结果、耗时、token/费用、代码 SHA、来源版本和云函数版本。公开附件脱敏，完整敏感记录私有归档。
4. 本阶段判据：可回答事实题正确率至少 80%；澄清/拒答守门题全部符合预期；日期、条件、数字的引用支持率 100%，未支持的官方事实断言为零。失败先保留首次结果，再修复复测；被用于调参的新题标为回归题，不再冒称独立验证。
5. 记录时延与成本分布、空响应/超时/配额失败及降级。时延预算仍按待办 D1 确认，不将当前规格 ≤2 秒写成已达标；计费缺数据时标未知。超预算、检测未完成或引用门槛失败时停止扩展，交付真实原因和可复查证据。

M2 完成判据：真实调用的逐题表及报告可复查；报告区分原题组、新题首次评测和调参后复测，明确 go/no-go、未通过项与下一步。模型返回了文字不等于引用验收通过。
