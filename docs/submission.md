# 作品说明模板与提交清单

状态：待填写模板。当前没有已完成的业务成果，以下各项按实际证据补充后才能勾选。

## a. 项目说明

- 作品名称、团队和版本：待定。
- 目标用户、使用场景、痛点及需求证据：待补充。
- 功能介绍、核心流程、演示录屏定位：待补充。

## b. 小程序与 AI 能力说明

列出实际使用的微信、云开发和 AI 能力，说明所在页面/流程、接口或服务、实现状态及证据。未使用的建议能力无需列为已实现。

## c. 创新点说明

从 AI 应用、场景、产品、技术、商业模式、用户体验六个维度中说明实际贡献，关联现有方案比较和可验证证据，避免只列概念。

## d. 技术实现

补充核心架构图、页面结构、前后端协作、关键代码片段、AI 接入方案、数据流和难点解决方案；给出安装、配置、运行和测试步骤。

## e. 成果展示

补充真实界面截图、关键流程视频、运行效果、测试记录、AI 评估、用户反馈；可附体验版或上线凭证。每项标明版本和日期。

## f. 历史说明

待核实是否存在往届成果。若无，填写“无”；若有，注明原版本、复用内容、本次改进及证据。第三方代码、素材和数据注明来源与授权。

## g. 落地规划

补充上线计划、目标用户触达、转化路径、增长设计、运营机制、留存方式、服务成本、商业闭环及后续版本方向。计划与已验证结果分别标注。

## 提交验收

- [ ] a–g 七项均填写完整，无未说明的占位符。
- [ ] 源码对应明确的 Git commit/tag，按说明可以安装、配置和运行。
- [ ] 视频可播放，核心流程可完整演示，截图与提交版本一致。
- [ ] 体验说明完整，适用时提供有效测试账号或体验二维码截图。
- [ ] 测试、AI 评估和演示阻断问题处理记录齐全。
- [ ] 历史成果与第三方来源说明准确。
- [ ] ZIP 名称为 `第九届传智杯-AI小程序赛道-作品名称.zip`，作品名已替换。
- [ ] ZIP 可正常解压，检查总大小（建议不超过 300MB）。
- [ ] 包内不含生产密钥、私人信息、无关缓存和依赖目录。
- [ ] 确认官方截止时刻、实际入口和团队报名状态。
- [ ] 完成上传并保存成功回执；记录提交时间、包名和对应 Git 版本。
