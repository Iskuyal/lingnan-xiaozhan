## 运行前登记

每轮记录：日期时间（Asia/Shanghai）、源码 commit、构建时间、预览码对应版本、微信及系统版本、设备型号、基础库、云环境代号、ai/timetable/newsSync 部署版本、审核提供方。凭据与原始 openid 不写进公开记录。云函数旧部署证据不自动绑定本次预览。

- 原生离线布局：`npm test` 构建后，用 CLI auto 连接 `dist`，运行 `node scripts/verify-lingnan-ui.cjs <新的输出目录>`。该脚本接管后使用内存夹具，不能登记真实云端或模型效果。
- 真实业务：先确认核账、预算、审核及云版本；准备两份可丢弃课表、获许可的截图和测试账号。现有课程先备份，不直接用整份替换试探生产数据。
- 现场真实 AI 的调用次数按实际图片分带、审核及业务子调用估算，不能把一次点击当成一次请求。查当前个人日/月用量与审核配额；触及额度、审核或记账故障即停止，不连续重试。

## 核心回归

| ID | 操作 | 预期 / 留存证据 |
| --- | --- | --- |
| R01 | 首页→部门→详情→返回；资讯列表→正文→来源 | 页面文字、返回及按钮可用；来源和日期可核对；保存新 UI 截图 |
| R02 | 从微信聊天选择可丢弃 Excel，进入校对后放弃 | 导入步骤可理解，旧课程数及内容不变；记录放弃前后读数 |
| R03 | 同份 Excel 校对一项后确认，退出重进 | 显示本人确认后的内容；记录课程数、星期、周次、节次、教师、地点；无学分版式独立记录 |
| R04 | 切周、网格/列表、横向查看周日和晚间课程；打开无法落格课程管理 | 固定节次轴、晚间课程、待补字段可达；管理可编辑/删除；取消删除不改数据 |
| R05 | 手工新增、修改、删除测试课程；修改测试设置后重进 | 仅指定字段改变，设置可读回；记录清理测试数据的结果 |
| R06 | 获许可截图→识别→校对→确认；另走放弃 | 六字段按预登记标准统计；确认前不写正式课表；记录耗时、费用、校对及临时文件清理，不凭成功画面宣称≥90% |
| R07 | 课表助手查询、缺字段追问、变更取消、相同变更确认 | 查询与真实课表一致；取消不写库，确认只改指定字段；按人工清单保留10题逐题结果 |
| R08 | 部门问答已知事实与资料缺失问题 | 按问题核对来源；无依据信息明确说明缺失；标题安全不等于回答正确；独立14题按冻结采集器执行 |
| R09 | 模型失败/超时、断网、额度不足 | 原有课表有可理解的读取状态；AI 失败有反馈，手工入口可达；不人为耗尽真实额度制造失败 |
| R10 | 答辩材料查阅→三轮→复盘→重答；返回与退出 | 轮次/草稿按契约保持；全文来源可查；真机返回手势、预览扫码、限额路径单列 |
| R11 | 目标日创建/编辑/删除/重进；校历来源；体测正常/缺项 | 本地保存与删除正确；日期适用范围清楚；体测保持参考估算，学校口径未确认时不称正式成绩 |
| R12 | 真机字号放大、窄屏、键盘和弹层关闭 | 操作不被遮挡，长文本可读可返回；记录机型与字号；320px浏览器辅助不代替微信原生 |

## 结果记录格式

每项保存：`ID、执行时间、版本/设备/云版、输入样本代号、预期、实际、passed/failed/blocked/not_run、耗时、调用数/成本、截图或视频、问题链接`。B1 准确率与 B2/B3 题数按[人工验收清单](manual-acceptance.md)计算；未知金额保留未知，脱敏证据不公开真实课表或姓名。

重启后本轮原生模拟器离线交互 **10/10通过，30张截图**，初轮blocked记录保留历史；新真机、真实上传保存与 AI 项仍为 **not_run**。取得实际结果后在证据目录新增版本化记录，不在本执行步骤里预填通过。
