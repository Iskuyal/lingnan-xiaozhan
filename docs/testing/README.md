# 验证指南

测试结论必须绑定版本和环境。**本地测试通过、云端部署成功、模拟器可用、真机效果达标是四件事**，任何一项都不能代替其他项。

| 层次 | 入口 | 产出与边界 |
| --- | --- | --- |
| 最终候选回归与录屏 | [2026-10-23步骤](submission-rehearsal-2026-10-23.md) | 核心主线、取消/确认、失败恢复与证据字段；这是执行步骤，不是通过记录 |
| 文档引用 | `npm run docs:check` | 本地链接、资源与锚点有效；不访问外网 |
| 本地代码 | [本地开发与验证](../development/local-setup.md) | 类型检查、构建、自动化测试；不调用真实模型证明效果 |
| 微信模拟器 | 同一指南中的 CLI 自动化步骤 | 页面操作、截图、端上云调用结果 |
| 真实环境人工验收 | [人工验收清单](manual-acceptance.md) | 真实课表、两账号、题集、设备、失败与降级 |
| 云端安全与版本 | [部署关卡](../development/cloud/deployment.md) | 配置、权限、函数版本与服务端归属边界 |

## 证据约定

1. 注明日期、Git 版本、云函数部署版本、环境或设备、输入、预期、实际结果。
2. AI 评估保留逐题或逐字段结果、耗时及成本；短文本冒烟不能代替问答准确率，合成小图不能代替真实截图识别。
3. 桩、模拟数据和真实样本分开标注，未执行与未通过分开记录。
4. 负责人确认的结论与可复查原始证据分开记录；证据缺失时标明待归档。
5. 当前边界更新到 [项目状态](../status.md)，历史记录保留在 [证据目录](../evidence/README.md)。
